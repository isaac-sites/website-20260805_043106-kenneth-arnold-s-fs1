## Introduction

The Rex Heflin photographs remain disputed because the central evidence is unusually strong in some respects and unusually incomplete in others. The four Polaroid images provide a sequence rather than a single isolated frame: three photographs allegedly show a metallic, domed object above the road near Santa Ana, California, and a fourth shows a dark ring-like feature that Heflin described as material left behind after the object departed. Supporters argue that the sequence, witness credibility, and later examinations of the images support the possibility of a genuine unknown object. Critics argue that the photographs cannot establish that interpretation because the original chain of custody was disrupted and conventional explanations, including a small object photographed at close range, remain possible.<span class="citation-link-wrap"><a class="citation-inline-link" href="https://www.nicap.org/reports/heflinhall.htm" target="_blank" rel="noopener noreferrer nofollow" aria-label="View source: nicap.org">[Nicap]</a><span class="citation-popover" role="note"><span class="citation-popover-source">nicap.org</span><span class="citation-popover-title">UFO Report</span><span class="citation-popover-snippet">UFO ReportAugust 3, 1965...</span><span class="citation-popover-meta">Published: August 3, 1965</span></span></span>

## The four-image sequence and what it shows


<div class="content-callout content-callout--key content-callout--takeaway" markdown="1">

The importance of the Heflin case comes from the fact that the evidence is a short photographic sequence. Heflin reported taking three photographs as the object moved across his field of view and a fourth after it appeared to leave the area. Unlike many UFO photographs that consist of one unclear object against the sky, the Heflin images contain landscape features such as the road, utility poles, and surrounding terrain that analysts have used to estimate scale, distance, and movement.<span class="citation-link-wrap"><a class="citation-inline-link" href="https://www.nicap.org/reports/heflinhall.htm" target="_blank" rel="noopener noreferrer nofollow" aria-label="View source: nicap.org">[Nicap]</a><span class="citation-popover" role="note"><span class="citation-popover-source">nicap.org</span><span class="citation-popover-title">UFO Report</span><span class="citation-popover-snippet">UFO ReportAugust 3, 1965...</span><span class="citation-popover-meta">Published: August 3, 1965</span></span></span>

</div>

The first three images are generally interpreted in two competing ways. Supporters of authenticity argue that the apparent changes in the object’s position and presentation are consistent with a moving object being photographed over several moments. They also point to features in the images that they believe suggest depth, lighting, and a structured object rather than a simple photographic mistake. NICAP investigators conducted an early examination involving witness interviews, site investigation, and photographic analysis, concluding that the case deserved continued attention.<span class="citation-link-wrap"><a class="citation-inline-link" href="https://www.nicap.org/reports/heflinhall.htm" target="_blank" rel="noopener noreferrer nofollow" aria-label="View source: nicap.org">[Nicap]</a><span class="citation-popover" role="note"><span class="citation-popover-source">nicap.org</span><span class="citation-popover-title">UFO Report</span><span class="citation-popover-snippet">UFO ReportAugust 3, 1965...</span><span class="citation-popover-meta">Published: August 3, 1965</span></span></span>

Sceptical analysts have focused on the same details but reached a different conclusion. The Condon Report’s photographic analysis considered whether the object could have been a small model or object close to the camera. Analyst William Hartmann argued that the apparent sharpness of the object compared with the background, along with the relationship between the object and nearby reference points, was more consistent with a nearby model than a large distant craft.<span class="citation-link-wrap"><a class="citation-inline-link" href="https://files.ncas.org/condon/text/s3chap02.htm" target="_blank" rel="noopener noreferrer nofollow" aria-label="View source: files.ncas.org">[files.ncas.org]</a><span class="citation-popover" role="note"><span class="citation-popover-source">files.ncas.org</span><span class="citation-popover-title">Condon Report Section III, Chapter 2: Photographic Evidence</span><span class="citation-popover-snippet">Condon Report Section III, Chapter 2: Photographic Evidence</span></span></span>

The fourth photograph has remained especially important in the debate because it appears to show something other than the object itself. Heflin described it as a smoke-like ring remaining after the object accelerated away. Supporters have treated this as an additional physical clue because it could represent a visible effect associated with the object’s departure. Critics have argued that the image is difficult to interpret independently and does not by itself establish an extraordinary cause.<span class="citation-link-wrap"><a class="citation-inline-link" href="https://www.nicap.org/reports/heflinhall.htm" target="_blank" rel="noopener noreferrer nofollow" aria-label="View source: nicap.org">[Nicap]</a><span class="citation-popover" role="note"><span class="citation-popover-source">nicap.org</span><span class="citation-popover-title">UFO Report</span><span class="citation-popover-snippet">UFO ReportAugust 3, 1965...</span><span class="citation-popover-meta">Published: August 3, 1965</span></span></span>

## Arguments over authenticity and image analysis

### The missing originals changed the evidence problem

The biggest weakness in the Heflin photographic record is the interruption in the chain of custody. After the photographs became public, Heflin reported that people claiming to represent the North American Aerospace Defense Command (NORAD) obtained the originals. NORAD later denied that it had sent anyone to collect them. The absence of the original Polaroids meant that some early investigators had to work from copies rather than the first-generation prints.<span class="citation-link-wrap"><a class="citation-inline-link" href="https://www.nicap.org/650803santaana_dir.htm" target="_blank" rel="noopener noreferrer nofollow" aria-label="View source: nicap.org">[Nicap]</a><span class="citation-popover" role="note"><span class="citation-popover-source">nicap.org</span><span class="citation-popover-title">UFO Report</span><span class="citation-popover-snippet">UFO Report...</span></span></span>

This mattered because photographic authentication depends heavily on original material. First-generation prints can preserve information about film characteristics, processing, markings, and possible alterations that may not survive in later reproductions. The loss of direct access did not prove that the photographs were false, but it reduced the ability of investigators to test competing explanations with confidence.<span class="citation-link-wrap"><a class="citation-inline-link" href="https://searchufos.com/cases/rex-heflin-ufo-photos.html" target="_blank" rel="noopener noreferrer nofollow" aria-label="View source: searchufos.com">[SearchUFOs]</a><span class="citation-popover" role="note"><span class="citation-popover-source">searchufos.com</span><span class="citation-popover-title">Search UFOs Rex Heflin UFO Photos — UFO Case File</span><span class="citation-popover-snippet">Search UFOs Rex Heflin UFO Photos — UFO Case File</span></span></span>

When the originals reportedly returned decades later, renewed analysis became possible. Supporters of the case argued that examining the original Polaroids rather than copies provided a stronger basis for judging whether the images were consistent with a genuine photographed object. However, the long period during which the images were unavailable remained an unresolved issue in evaluating their complete history.<span class="citation-link-wrap"><a class="citation-inline-link" href="https://searchufos.com/cases/rex-heflin-ufo-photos.html" target="_blank" rel="noopener noreferrer nofollow" aria-label="View source: searchufos.com">[SearchUFOs]</a><span class="citation-popover" role="note"><span class="citation-popover-source">searchufos.com</span><span class="citation-popover-title">Search UFOs Rex Heflin UFO Photos — UFO Case File</span><span class="citation-popover-snippet">Search UFOs Rex Heflin UFO Photos — UFO Case File</span></span></span>

### The small-model explanation versus the genuine-object interpretation

The main technical disagreement concerns scale. A photograph alone does not automatically reveal whether an object is large and distant or small and close to the camera. Analysts therefore examine focus, lighting, perspective, shadows, and the object’s relationship to known features in the scene. The Condon Report emphasised that photographic evidence requires more than an unusual appearance; analysts must determine whether ordinary explanations can be ruled out.<span class="citation-link-wrap"><a class="citation-inline-link" href="https://files.ncas.org/condon/text/s3chap02.htm" target="_blank" rel="noopener noreferrer nofollow" aria-label="View source: files.ncas.org">[files.ncas.org]</a><span class="citation-popover" role="note"><span class="citation-popover-source">files.ncas.org</span><span class="citation-popover-title">Condon Report Section III, Chapter 2: Photographic Evidence</span><span class="citation-popover-snippet">Condon Report Section III, Chapter 2: Photographic Evidence</span></span></span>

Hartmann’s Condon Report analysis placed the Heflin photographs among cases where a conventional explanation appeared plausible. His assessment suggested that a small object photographed near the camera could reproduce important visual characteristics of the images. This interpretation became one of the strongest arguments against treating the photographs as evidence of an unknown aircraft.<span class="citation-link-wrap"><a class="citation-inline-link" href="https://files.ncas.org/condon/text/s3chap02.htm" target="_blank" rel="noopener noreferrer nofollow" aria-label="View source: files.ncas.org">[files.ncas.org]</a><span class="citation-popover" role="note"><span class="citation-popover-source">files.ncas.org</span><span class="citation-popover-title">Condon Report Section III, Chapter 2: Photographic Evidence</span><span class="citation-popover-snippet">Condon Report Section III, Chapter 2: Photographic Evidence</span></span></span>

## Why the evidence remains disputed

The Heflin photographs occupy an unusual position between strong documentation and incomplete verification. The case has advantages that many UFO photographs lack: a named witness, a precise date and location, multiple images, and attempts at investigation by different groups. At the same time, it lacks some of the features needed for a decisive conclusion, especially an uninterrupted record of the original photographs from the moment they were taken through every later examination.<span class="citation-link-wrap"><a class="citation-inline-link" href="https://www.nicap.org/reports/heflinhall.htm" target="_blank" rel="noopener noreferrer nofollow" aria-label="View source: nicap.org">[Nicap]</a><span class="citation-popover" role="note"><span class="citation-popover-source">nicap.org</span><span class="citation-popover-title">UFO Report</span><span class="citation-popover-snippet">UFO ReportAugust 3, 1965...</span><span class="citation-popover-meta">Published: August 3, 1965</span></span></span>

The disagreement is also shaped by different standards of proof. Supporters often argue that the photographs are difficult to explain through ordinary means and that the witness account and image sequence reinforce each other. Sceptics argue that “unidentified” does not mean “extraordinary” and that a photograph must exclude plausible conventional explanations before it can establish an unknown phenomenon. The Condon Report’s broader approach to UFO photography reflected this caution, noting that unusual images frequently remain inconclusive when key measurements or reliable controls are unavailable.<span class="citation-link-wrap"><a class="citation-inline-link" href="https://files.ncas.org/condon/text/s3chap02.htm" target="_blank" rel="noopener noreferrer nofollow" aria-label="View source: files.ncas.org">[files.ncas.org]</a><span class="citation-popover" role="note"><span class="citation-popover-source">files.ncas.org</span><span class="citation-popover-title">Condon Report Section III, Chapter 2: Photographic Evidence</span><span class="citation-popover-snippet">Condon Report Section III, Chapter 2: Photographic Evidence</span></span></span>

No accepted consensus has emerged that either authenticates the photographs as evidence of an unknown craft or proves them to be a hoax. The lasting significance of the Heflin images comes from the tension between their documentary strengths and their evidential limitations: they preserve a rare photographic sequence with a credible investigative history, but they do not contain enough uncontested information to settle the question of what was photographed.<span class="citation-link-wrap"><a class="citation-inline-link" href="https://searchufos.com/cases/rex-heflin-ufo-photos.html" target="_blank" rel="noopener noreferrer nofollow" aria-label="View source: searchufos.com">[SearchUFOs]</a><span class="citation-popover" role="note"><span class="citation-popover-source">searchufos.com</span><span class="citation-popover-title">Search UFOs Rex Heflin UFO Photos — UFO Case File</span><span class="citation-popover-snippet">Search UFOs Rex Heflin UFO Photos — UFO Case File</span></span></span>

    return encodeURIComponent(String(value || '').replace(/\s+/g, ' ').trim()).replace(/%20/g, '+');
  }
  function buildUrl(query, reference, marketId) {
    var cfg = markets[marketId] || markets[defaultMarket];
    if (!cfg) return '#';
    var template = String(cfg.url_template || 'https://www.ebay.com/sch/i.html?_nkw={query}');
    var url = template.replace('{query}', encodeQuery(query || '')).replace('{query_plain}', String(query || ''));
    var joiner = url.indexOf('?') >= 0 ? '&' : '?';
    var params = [];
    if (cfg.mkrid) params.push('mkrid=' + encodeURIComponent(cfg.mkrid));
    if (cfg.campaign_id) params.push('campid=' + encodeURIComponent(cfg.campaign_id));
    params.push('mkevt=1');
    params.push('mkcid=1');
    params.push('toolid=' + encodeURIComponent(cfg.tool_id || '10001'));
    if (reference) params.push('customid=' + encodeURIComponent(reference).slice(0, 256));
    return url + joiner + params.join('&');
  }
  function domainLabel(marketId) {
    var cfg = markets[marketId] || markets[defaultMarket] || {};
    return cfg.domain_label || 'eBay';
  }
  function flagClass(marketId) {
    return 'fr-ebay-market-flag fr-ebay-market-flag--' + String(marketId || '').toLowerCase().replace(/_/g, '-').replace(/[^a-z0-9-]+/g, '');
  }
  function closeMenu(section) {
    var menu = section.querySelector('[data-ebay-market-menu]');
    var trigger = section.querySelector('[data-ebay-market-trigger]');
    var picker = section.querySelector('.fr-ebay-market-picker');
    if (menu) menu.hidden = true;
    if (trigger) trigger.setAttribute('aria-expanded', 'false');
    if (picker) picker.classList.remove('fr-ebay-market-picker--open');
  }
  function availableMarkets(section) {
    var select = section.querySelector('[data-ebay-market-select]');
    if (select) {
      return Array.prototype.slice.call(select.options)
        .map(function (option) { return option.value; })
        .filter(function (marketId) { return !!markets[marketId]; });
    }
    return Array.prototype.slice.call(section.querySelectorAll('[data-ebay-market-button]'))
      .map(function (button) { return button.getAttribute('data-ebay-market-button'); })
      .filter(function (marketId) { return !!markets[marketId]; });
  }
  function applyMarket(section, marketId, persist) {
    var available = availableMarkets(section);
    if (available.indexOf(marketId)< 0) marketId = available[0] || defaultMarket;
    Array.prototype.slice.call(section.querySelectorAll('[data-ebay-localized-link]')).forEach(function (link) {
      var query = link.getAttribute('data-ebay-query') || '';
      var reference = link.getAttribute('data-ebay-reference') || '';
      link.setAttribute('href', buildUrl(query, reference, marketId));
    });
    var select = section.querySelector('[data-ebay-market-select]');
    if (select && available.indexOf(marketId) >= 0) select.value = marketId;
    var selectedText = marketId;
    if (select && select.selectedIndex >= 0) selectedText = select.options[select.selectedIndex].text;
    Array.prototype.slice.call(section.querySelectorAll('[data-ebay-selected-market-label]')).forEach(function (label) {
      label.textContent = selectedText;
    });
    Array.prototype.slice.call(section.querySelectorAll('[data-ebay-selected-market-flag], [data-ebay-trigger-market-flag]')).forEach(function (flag) {
      flag.className = flagClass(marketId);
    });
    Array.prototype.slice.call(section.querySelectorAll('[data-ebay-trigger-market-label]')).forEach(function (label) {
      label.textContent = selectedText;
    });
    Array.prototype.slice.call(section.querySelectorAll('[data-ebay-domain-label]')).forEach(function (label) {
      label.textContent = domainLabel(marketId);
    });
    Array.prototype.slice.call(section.querySelectorAll('[data-ebay-market-option]')).forEach(function (button) {
      button.setAttribute('aria-selected', button.getAttribute('data-ebay-market-option') === marketId ? 'true' : 'false');
    });
    Array.prototype.slice.call(section.querySelectorAll('[data-ebay-market-button]')).forEach(function (button) {
      var active = button.getAttribute('data-ebay-market-button') === marketId;
      button.setAttribute('aria-pressed', active ? 'true' : 'false');
    });
    section.setAttribute('data-ebay-selected-market', marketId);
    if (persist) {
      try { if (window.localStorage) localStorage.setItem('phoenix-ebay-market', marketId); } catch (err) {}
    }
    closeMenu(section);
  }
  sections.forEach(function (section) {
    if (section.getAttribute('data-ebay-localized-init') === '1') return;
    section.setAttribute('data-ebay-localized-init', '1');
    var available = availableMarkets(section);
    var marketId = defaultMarket;
    if (window.PhoenixAffiliateLocation && window.PhoenixAffiliateLocation.inferMarket) {
      marketId = window.PhoenixAffiliateLocation.inferMarket(available, {
        storageKey: 'phoenix-ebay-market',
        defaultMarket: defaultMarket
      });
    } else if (available.indexOf(defaultMarket)< 0) {
      marketId = available[0] || defaultMarket;
    }
    var select = section.querySelector('[data-ebay-market-select]');
    if (select) {
      select.addEventListener('change', function () {
        applyMarket(section, select.value, true);
      });
    }
    var trigger = section.querySelector('[data-ebay-market-trigger]');
    var menu = section.querySelector('[data-ebay-market-menu]');
    if (trigger && menu) {
      trigger.addEventListener('click', function (event) {
        event.stopPropagation();
        var expanded = trigger.getAttribute('aria-expanded') === 'true';
        menu.hidden = expanded;
        trigger.setAttribute('aria-expanded', expanded ? 'false' : 'true');
        var picker = trigger.closest('.fr-ebay-market-picker');
        if (picker) picker.classList.toggle('fr-ebay-market-picker--open', !expanded);
      });
      Array.prototype.slice.call(menu.querySelectorAll('[data-ebay-market-option]')).forEach(function (button) {
        button.addEventListener('click', function (event) {
          event.stopPropagation();
          applyMarket(section, button.getAttribute('data-ebay-market-option'), true);
        });
      });
      document.addEventListener('click', function () { closeMenu(section); });
    }
    Array.prototype.slice.call(section.querySelectorAll('[data-ebay-market-button]')).forEach(function (button) {
      button.addEventListener('click', function () {
        applyMarket(section, button.getAttribute('data-ebay-market-button'), true);
      });
    });
    applyMarket(section, marketId, false);
  });
})();
