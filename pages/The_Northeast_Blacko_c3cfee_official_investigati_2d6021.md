## Introduction

The Federal Power Commission (FPC) investigation into the Northeast Blackout of 1965 transformed the event from a single equipment failure into a major study of how modern electricity networks could fail. Ordered immediately after the outage by President Lyndon B. Johnson, the investigation examined operational records, relay settings, power flows, equipment responses and restoration difficulties to determine how a local disturbance developed into a regional collapse. The Commission’s December 1965 report concluded that the blackout began with the unintended operation of a protective relay on a transmission line in Ontario and spread because the interconnected power system lacked sufficient safeguards against cascading failures.<span class="citation-link-wrap"><a class="citation-inline-link" href="https://www.presidency.ucsb.edu/documents/memorandum-concerning-the-power-failure-the-northeastern-united-states" target="_blank" rel="noopener noreferrer nofollow" aria-label="View source: presidency.ucsb.edu">[The American Presidency Project]</a><span class="citation-popover" role="note"><span class="citation-popover-source">presidency.ucsb.edu</span><span class="citation-popover-snippet">The American Presidency ProjectMemorandum Concerning the Power Failure in the Northeastern United States &#124; The American Presidency Projec...</span></span></span>

The importance of the investigation was not only identifying the initiating fault. Its larger finding was that reliability depended on coordination across many utilities rather than the performance of individual power stations alone. The FPC’s recommendations reshaped transmission planning, emergency procedures, system monitoring and cooperation between electricity providers throughout North America.<span class="citation-link-wrap"><a class="citation-inline-link" href="https://books.google.com/books/about/Northeast_Power_Failure.html?id=dUNSAQAAIAAJ" target="_blank" rel="noopener noreferrer nofollow" aria-label="View source: books.google.com">[Google Books]</a><span class="citation-popover" role="note"><span class="citation-popover-source">books.google.com</span><span class="citation-popover-title">Northeast Power Failure</span><span class="citation-popover-snippet">Google BooksNortheast Power Failure: November 9 and 10, 1965: a Report to the President - United States. ## The investigation timeline and technical records

The FPC investigation began within hours of the blackout. President Johnson directed FPC Chairman Joseph C. Swidler to conduct a detailed study of the failure, identify its causes and recommend measures to prevent a recurrence. The investigation involved federal officials alongside engineers from affected American and Canadian utilities, allowing investigators to compare operating data from across the interconnected grid.<span class="citation-link-wrap"><a class="citation-inline-link" href="https://www.presidency.ucsb.edu/documents/memorandum-concerning-the-power-failure-the-northeastern-united-states" target="_blank" rel="noopener noreferrer nofollow" aria-label="View source: presidency.ucsb.edu">[The American Presidency Project]</a><span class="citation-popover" role="note"><span class="citation-popover-source">presidency.ucsb.edu</span><span class="citation-popover-snippet">The American Presidency ProjectMemorandum Concerning the Power Failure in the Northeastern United States &#124; The American Presidency Projec...</span></span></span>

Rather than relying on eyewitness accounts alone, investigators reconstructed the event from technical evidence. The final report examined relay operations, circuit-breaker actions, generator responses, transmission-line loading and the sequence in which different parts of the grid separated. The report included a timeline of events from 9–10 November 1965, diagrams of transmission-line openings and analysis of restoration problems after the system collapsed.<span class="citation-link-wrap"><a class="citation-inline-link" href="https://books.google.com/books/about/Northeast_Power_Failure.html?id=dUNSAQAAIAAJ" target="_blank" rel="noopener noreferrer nofollow" aria-label="View source: books.google.com">[Google Books]</a><span class="citation-popover" role="note"><span class="citation-popover-source">books.google.com</span><span class="citation-popover-title">Northeast Power Failure</span><span class="citation-popover-snippet">Google BooksNortheast Power Failure: November 9 and 10, 1965: a Report to the President - United States. Federal Power Commission - Goog...</span></span></span>

The reconstruction showed that the blackout was a cascading failure. A protective relay — an automatic device designed to disconnect electrical equipment when dangerous conditions occur — operated incorrectly because of its setting. The initial trip changed power flows throughout the network, increasing stress on other transmission paths. Additional protective devices then operated as designed, but the combined effect was the loss of large sections of the interconnected system.<span class="citation-link-wrap"><a class="citation-inline-link" href="https://info.ornl.gov/sites/publications/Files/Pub170005.pdf" target="_blank" rel="noopener noreferrer nofollow" aria-label="View source: info.ornl.gov">[ORNL Info]</a><span class="citation-popover" role="note"><span class="citation-popover-source">info.ornl.gov</span><span class="citation-popover-snippet">ORNL InfoORNL/SPR-2021/2345March 12, 2026...</span><span class="citation-popover-meta">Published: March 12, 2026</span></span></span>

## Evidence behind the official cause

The FPC’s central finding was that the first failure was not caused by a shortage of generation, deliberate action or a widespread equipment breakdown. Investigators traced the beginning of the disturbance to a protective relay setting associated with a transmission line connected to Ontario Hydro’s Sir Adam Beck generating complex. The relay responded to conditions it interpreted as requiring disconnection, although the wider system conditions did not require that action.<span class="citation-link-wrap"><a class="citation-inline-link" href="https://info.ornl.gov/sites/publications/Files/Pub170005.pdf" target="_blank" rel="noopener noreferrer nofollow" aria-label="View source: info.ornl.gov">[ORNL Info]</a><span class="citation-popover" role="note"><span class="citation-popover-source">info.ornl.gov</span><span class="citation-popover-snippet">ORNL InfoORNL/SPR-2021/2345March 12, 2026...</span><span class="citation-popover-meta">Published: March 12, 2026</span></span></span>

The evidence showed that the relay itself was functioning according to its programmed settings; the problem was that the setting was inappropriate for the role it was expected to perform. This distinction became an important engineering lesson. The blackout was not simply a story of a failed component but of a mismatch between protection design and the behaviour of a highly interconnected grid.<span class="citation-link-wrap"><a class="citation-inline-link" href="https://books.google.com/books/about/Northeast_Power_Failure.html?id=dUNSAQAAIAAJ" target="_blank" rel="noopener noreferrer nofollow" aria-label="View source: books.google.com">[Google Books]</a><span class="citation-popover" role="note"><span class="citation-popover-source">books.google.com</span><span class="citation-popover-title">Northeast Power Failure</span><span class="citation-popover-snippet">Google BooksNortheast Power Failure: November 9 and 10, 1965: a Report to the President - United States. Federal Power Commission - Goog...</span></span></span>

Investigators also focused on why the disturbance spread so quickly. By 1965, regional utilities had increasingly connected their systems to exchange power and improve efficiency. The FPC found that these links created benefits but also introduced new risks because a failure in one area could affect distant systems. The investigation highlighted the need for stronger coordination, better studies of system behaviour under abnormal conditions and improved communication between utilities.<span class="citation-link-wrap"><a class="citation-inline-link" href="https://books.google.com/books?id=_ydHAQAAIAAJ" target="_blank" rel="noopener noreferrer nofollow" aria-label="View source: books.google.com">[Google Books]</a><span class="citation-popover" role="note"><span class="citation-popover-source">books.google.com</span><span class="citation-popover-snippet">Google BooksPrevention of Power Failures: An Analysis and Recommendations Pertaining to... - United States. Federal Power Commission - G...</span></span></span>

The restoration process provided another area of evidence. The FPC examined how operators brought the network back online and found that recovery depended on careful coordination between companies that had previously operated with considerable independence. The report treated restoration capability as a reliability issue in its own right, not merely an emergency response after a failure.<span class="citation-link-wrap"><a class="citation-inline-link" href="https://books.google.com/books/about/Northeast_Power_Failure.html?id=dUNSAQAAIAAJ" target="_blank" rel="noopener noreferrer nofollow" aria-label="View source: books.google.com">[Google Books]</a><span class="citation-popover" role="note"><span class="citation-popover-source">books.google.com</span><span class="citation-popover-title">Northeast Power Failure</span><span class="citation-popover-snippet">Google BooksNortheast Power Failure: November 9 and 10, 1965: a Report to the President - United States. ## Recommendations that reshaped grid planning

The FPC’s recommendations changed the way electricity reliability was approached in the United States. Before 1965, many reliability practices depended heavily on voluntary coordination among utilities. The blackout demonstrated that large interconnected systems required more formal planning, shared standards and continuous evaluation of possible failure scenarios.<span class="citation-link-wrap"><a class="citation-inline-link" href="https://info.ornl.gov/sites/publications/Files/Pub170005.pdf" target="_blank" rel="noopener noreferrer nofollow" aria-label="View source: info.ornl.gov">[ORNL Info]</a><span class="citation-popover" role="note"><span class="citation-popover-source">info.ornl.gov</span><span class="citation-popover-snippet">ORNL InfoORNL/SPR-2021/2345March 12, 2026...</span><span class="citation-popover-meta">Published: March 12, 2026</span></span></span>

A major outcome was the creation of stronger industry-wide reliability arrangements. The FPC established an Advisory Committee on Reliability of Bulk Power Supply to examine how major outages could be prevented, leading to further studies and recommendations on the operation of the nation’s power systems. Later reliability organisations and regional coordination structures developed from this broader movement towards coordinated grid management.<span class="citation-link-wrap"><a class="citation-inline-link" href="https://info.ornl.gov/sites/publications/Files/Pub170005.pdf" target="_blank" rel="noopener noreferrer nofollow" aria-label="View source: info.ornl.gov">[ORNL Info]</a><span class="citation-popover" role="note"><span class="citation-popover-source">info.ornl.gov</span><span class="citation-popover-snippet">ORNL InfoORNL/SPR-2021/2345March 12, 2026...</span><span class="citation-popover-meta">Published: March 12, 2026</span></span></span>

* **Improved protection systems:** Utilities were urged to review relay settings and protection schemes so that individual equipment actions would not unintentionally trigger wider failures.<span class="citation-link-wrap"><a class="citation-inline-link" href="https://books.google.com/books?id=_ydHAQAAIAAJ" target="_blank" rel="noopener noreferrer nofollow" aria-label="View source: books.google.com">[Google Books]</a><span class="citation-popover" role="note"><span class="citation-popover-source">books.google.com</span><span class="citation-popover-snippet">Google BooksPrevention of Power Failures: An Analysis and Recommendations Pertaining to... - United States. ## What the investigation changed about grid reliability

The lasting significance of the FPC investigation was its shift in engineering thinking. Before the blackout, reliability was often considered mainly in terms of whether individual plants and lines were operating correctly. The 1965 findings showed that the behaviour of the entire network could be more important than the condition of any single component.<span class="citation-link-wrap"><a class="citation-inline-link" href="https://books.google.com/books?id=_ydHAQAAIAAJ" target="_blank" rel="noopener noreferrer nofollow" aria-label="View source: books.google.com">[Google Books]</a><span class="citation-popover" role="note"><span class="citation-popover-source">books.google.com</span><span class="citation-popover-snippet">Google BooksPrevention of Power Failures: An Analysis and Recommendations Pertaining to... - United States. Federal Power Commission - G...</span></span></span>

The investigation also established a pattern that continues to influence power-system analysis: major outages must be studied as chains of events. Engineers now routinely examine how protective equipment, transmission constraints, operator decisions and system design interact during disturbances. The Northeast Blackout became a defining example of why interconnected grids require coordinated reliability standards rather than isolated utility-by-utility planning.<span class="citation-link-wrap"><a class="citation-inline-link" href="https://books.google.com/books?id=_ydHAQAAIAAJ" target="_blank" rel="noopener noreferrer nofollow" aria-label="View source: books.google.com">[Google Books]</a><span class="citation-popover" role="note"><span class="citation-popover-source">books.google.com</span><span class="citation-popover-snippet">Google BooksPrevention of Power Failures: An Analysis and Recommendations Pertaining to... - United States. Federal Power Commission - G...</span></span></span>

The FPC report therefore did more than explain what happened on 9 November 1965. It provided the technical foundation for a new approach to managing large electric networks, where preventing a cascade became as important as maintaining individual pieces of equipment.<span class="citation-link-wrap"><a class="citation-inline-link" href="https://books.google.com/books/about/Northeast_Power_Failure.html?id=dUNSAQAAIAAJ" target="_blank" rel="noopener noreferrer nofollow" aria-label="View source: books.google.com">[Google Books]</a><span class="citation-popover" role="note"><span class="citation-popover-source">books.google.com</span><span class="citation-popover-title">Northeast Power Failure</span><span class="citation-popover-snippet">Google BooksNortheast Power Failure: November 9 and 10, 1965: a Report to the President - United States.       else if (navigator.language) languages = [navigator.language];
    } catch (err) {}
    for (var i = 0; i< languages.length; i += 1) {
      var normalized = normalize(languages[i]);
      if (!normalized) continue;
      if (localeMarketMap[normalized]) {
        exactMarket = localeMarketMap[normalized];
        break;
      }
      var languageOnly = normalized.split('-')[0];
      if (!languageMarket && localeMarketMap[languageOnly]) languageMarket = localeMarketMap[languageOnly];
    }
    return { exact: exactMarket, language: languageMarket };
  }
  function inferFromLocale() {
    var matches = localeMatches();
    return matches.exact || matches.language || '';
  }
  function inferFromTimezone() {
    var tz = '';
    try { tz = String(Intl.DateTimeFormat().resolvedOptions().timeZone || ''); } catch (err) {}
    if (!tz) return '';
    for (var i = 0; i< timezoneRules.length; i += 1) {
      var rule = timezoneRules[i] || {};
      try {
        if (new RegExp(rule.pattern).test(tz)) return rule.market;
      } catch (err) {}
    }
    return '';
  }
  function inferMarket(available, options) {
    available = Array.isArray(available) ? available : [];
    options = options || {};
    var storageKey = options.storageKey || 'phoenix-affiliate-market';
    try {
      var saved = window.localStorage && localStorage.getItem(storageKey);
      if (saved && available.indexOf(saved) >= 0) return saved;
    } catch (err) {}
    var timezoneMarket = inferFromTimezone();
    if (timezoneMarket && available.indexOf(timezoneMarket) >= 0) return timezoneMarket;
    var localeMarkets = localeMatches();
    if (localeMarkets.exact && available.indexOf(localeMarkets.exact) >= 0) return localeMarkets.exact;
    if (localeMarkets.language && available.indexOf(localeMarkets.language) >= 0) return localeMarkets.language;
    if (options.defaultMarket && available.indexOf(options.defaultMarket) >= 0) return options.defaultMarket;
    return available[0] || '';
  }
  window.PhoenixAffiliateLocation = {
    normalize: normalize,
    inferMarket: inferMarket,
    inferFromLocale: inferFromLocale,
    inferFromTimezone: inferFromTimezone
  };
