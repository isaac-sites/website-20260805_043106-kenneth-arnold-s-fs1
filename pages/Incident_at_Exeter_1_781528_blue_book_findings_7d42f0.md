## Introduction

Project Blue Book’s investigation of the [Incident at Exeter]({{ 'incident-at-exeter-1965/' | relative_url }}) (1965) ended without a confirmed explanation. The U.S. Air Force reviewed the sighting through its official UFO investigation programme, examined possible conventional causes including military aircraft activity connected with Operation Big Blast, and ultimately retained the case as “unidentified”. This classification did not mean the Air Force accepted an extraordinary explanation; it meant investigators could not match the reported event to a verified conventional cause.<span class="citation-link-wrap"><a class="citation-inline-link" href="https://www.govweird.com/topics/ufo/project-blue-book/exeter-nh-september-1965" target="_blank" rel="noopener noreferrer nofollow" aria-label="View source: govweird.com">[govweird]</a><span class="citation-popover" role="note"><span class="citation-popover-source">govweird.com</span><span class="citation-popover-title">exeter nh september 1965</span><span class="citation-popover-snippet">Project Blue Book: Exeter, New Hampshire, September 1965 · govweirdSeptember 3, 1965...</span><span class="citation-popover-meta">Published: september 1965</span></span></span>

The Exeter investigation became significant because it exposed a tension inside Project Blue Book: the programme was expected to reduce uncertainty by identifying ordinary causes, but some cases remained unresolved even after official review. In Exeter’s case, the combination of multiple witnesses, police involvement, and disagreement over the proposed aircraft explanation prevented investigators from closing the file with a definitive answer.<span class="citation-link-wrap"><a class="citation-inline-link" href="https://www.govweird.com/topics/ufo/project-blue-book/exeter-nh-september-1965" target="_blank" rel="noopener noreferrer nofollow" aria-label="View source: govweird.com">[govweird]</a><span class="citation-popover" role="note"><span class="citation-popover-source">govweird.com</span><span class="citation-popover-title">exeter nh september 1965</span><span class="citation-popover-snippet">Project Blue Book: Exeter, New Hampshire, September 1965 · govweirdSeptember 3, 1965...</span><span class="citation-popover-meta">Published: september 1965</span></span></span>

## Air Force investigation records

Project Blue Book treated the Exeter report as an official case file rather than simply a public controversy. The investigation was conducted through the Air Force’s standard process of collecting witness accounts, examining possible explanations, and assigning a final classification. The surviving records are part of the Project Blue Book case files now held by the National Archives, which preserve thousands of UFO investigation documents from the programme’s operating years.<span class="citation-link-wrap"><a class="citation-inline-link" href="https://www.archives.gov/research/military/air-force/ufos" target="_blank" rel="noopener noreferrer nofollow" aria-label="View source: archives.gov">[National Archives]</a><span class="citation-popover" role="note"><span class="citation-popover-source">archives.gov</span><span class="citation-popover-title">National Archives Project BLUE BOOK</span><span class="citation-popover-snippet">National ArchivesProject BLUE BOOK - Unidentified Flying Objects &#124; National Archives...</span></span></span>

The Exeter file was recorded as Project Blue Book Case 9706. Investigators documented reports from Norman Muscarello and Exeter police officers Eugene Bertrand and David Hunt, whose accounts became central to later discussion of the case. According to summaries of the case records, the investigators considered the observers, particularly the police witnesses, to be credible, while still being unable to establish exactly what they had seen.<span class="citation-link-wrap"><a class="citation-inline-link" href="https://www.govweird.com/topics/ufo/project-blue-book/exeter-nh-september-1965" target="_blank" rel="noopener noreferrer nofollow" aria-label="View source: govweird.com">[govweird]</a><span class="citation-popover" role="note"><span class="citation-popover-source">govweird.com</span><span class="citation-popover-title">exeter nh september 1965</span><span class="citation-popover-snippet">Project Blue Book: Exeter, New Hampshire, September 1965 · govweirdSeptember 3, 1965...</span><span class="citation-popover-meta">Published: september 1965</span></span></span>

A key feature of the investigation was that the Air Force did not simply dismiss the sighting immediately. Instead, officials explored several possible explanations. These included astronomical causes and aircraft activity in the area, especially operations connected with Strategic Air Command and NORAD training activity. The difficulty was that these explanations did not fully account for the details reported by the witnesses, particularly their claims that the object appeared close, silent, and unlike a conventional aircraft.<span class="citation-link-wrap"><a class="citation-inline-link" href="https://www.govweird.com/topics/ufo/project-blue-book/exeter-nh-september-1965" target="_blank" rel="noopener noreferrer nofollow" aria-label="View source: govweird.com">[govweird]</a><span class="citation-popover" role="note"><span class="citation-popover-source">govweird.com</span><span class="citation-popover-title">exeter nh september 1965</span><span class="citation-popover-snippet">Project Blue Book: Exeter, New Hampshire, September 1965 · govweirdSeptember 3, 1965...</span><span class="citation-popover-meta">Published: september 1965</span></span></span>

The documentary record therefore shows a more complicated picture than either a simple “debunking” or a confirmation of an unknown craft. Blue Book investigated the report within its normal framework, but the available evidence did not allow investigators to move the case into the identified category.<span class="citation-link-wrap"><a class="citation-inline-link" href="https://www.govweird.com/topics/ufo/project-blue-book/exeter-nh-september-1965" target="_blank" rel="noopener noreferrer nofollow" aria-label="View source: govweird.com">[govweird]</a><span class="citation-popover" role="note"><span class="citation-popover-source">govweird.com</span><span class="citation-popover-title">exeter nh september 1965</span><span class="citation-popover-snippet">Project Blue Book: Exeter, New Hampshire, September 1965 · govweirdSeptember 3, 1965...</span><span class="citation-popover-meta">Published: september 1965</span></span></span>

## Operation Big Blast explanations

The main conventional explanation considered by the Air Force involved Operation Big Blast, a large military training exercise taking place in the region during the period of the sighting. Investigators examined whether aircraft involved in the exercise, including aircraft associated with Strategic Air Command operations, could explain the reported lights and movements.<span class="citation-link-wrap"><a class="citation-inline-link" href="https://www.govweird.com/topics/ufo/project-blue-book/exeter-nh-september-1965" target="_blank" rel="noopener noreferrer nofollow" aria-label="View source: govweird.com">[govweird]</a><span class="citation-popover" role="note"><span class="citation-popover-source">govweird.com</span><span class="citation-popover-title">exeter nh september 1965</span><span class="citation-popover-snippet">Project Blue Book: Exeter, New Hampshire, September 1965 · govweirdSeptember 3, 1965...</span><span class="citation-popover-meta">Published: september 1965</span></span></span>

This explanation became the centre of the controversy because it appeared plausible from an operational perspective but did not satisfy the witnesses. Police officers Bertrand and Hunt argued that their observation did not resemble distant aircraft activity. Their objections focused on the reported proximity of the object, its apparent lack of normal aircraft features, and the absence of engine noise.<span class="citation-link-wrap"><a class="citation-inline-link" href="https://www.scribd.com/document/30873703/Exeter-Part-1-MUFON-Case-File" target="_blank" rel="noopener noreferrer nofollow" aria-label="View source: scribd.com">[Scribd]</a><span class="citation-popover" role="note"><span class="citation-popover-source">scribd.com</span><span class="citation-popover-snippet">Exeter Part 1 MUFON Case File &#124; PDF &#124; Aerial Refueling &#124; Unidentified Flying Object...</span></span></span>

The disagreement illustrates one of the recurring problems in UFO investigations: a possible match in military records does not automatically prove that a reported sighting has been explained. Investigators must show that the timing, location, appearance, and behaviour of the proposed source align with the witness reports. In Exeter, the Air Force could identify relevant aircraft activity but did not establish that those aircraft were responsible for the specific object observed by the witnesses.<span class="citation-link-wrap"><a class="citation-inline-link" href="https://www.govweird.com/topics/ufo/project-blue-book/exeter-nh-september-1965" target="_blank" rel="noopener noreferrer nofollow" aria-label="View source: govweird.com">[govweird]</a><span class="citation-popover" role="note"><span class="citation-popover-source">govweird.com</span><span class="citation-popover-title">exeter nh september 1965</span><span class="citation-popover-snippet">Project Blue Book: Exeter, New Hampshire, September 1965 · govweirdSeptember 3, 1965...</span><span class="citation-popover-meta">Published: september 1965</span></span></span>

Later accounts of the case often describe the Big Blast explanation as either an attempted resolution that failed or as evidence of premature dismissal. The official record is more restrained: the Air Force considered the possibility but ultimately did not classify the Exeter report as solved.<span class="citation-link-wrap"><a class="citation-inline-link" href="https://www.govweird.com/topics/ufo/project-blue-book/exeter-nh-september-1965" target="_blank" rel="noopener noreferrer nofollow" aria-label="View source: govweird.com">[govweird]</a><span class="citation-popover" role="note"><span class="citation-popover-source">govweird.com</span><span class="citation-popover-title">exeter nh september 1965</span><span class="citation-popover-snippet">Project Blue Book: Exeter, New Hampshire, September 1965 · govweirdSeptember 3, 1965...</span><span class="citation-popover-meta">Published: september 1965</span></span></span>

## Why Project Blue Book left Exeter unidentified

The final classification of Exeter as unidentified was a statement about evidence, not a declaration about the nature of the object. Project Blue Book used “unidentified” for reports where investigators could not determine a reliable cause after review. The Air Force’s overall conclusion when Blue Book ended was that unidentified cases did not demonstrate extraterrestrial vehicles or a threat to national security, but some individual reports remained unresolved.<span class="citation-link-wrap"><a class="citation-inline-link" href="https://www.archives.gov/research/military/air-force/ufos" target="_blank" rel="noopener noreferrer nofollow" aria-label="View source: archives.gov">[National Archives]</a><span class="citation-popover" role="note"><span class="citation-popover-source">archives.gov</span><span class="citation-popover-title">National Archives Project BLUE BOOK</span><span class="citation-popover-snippet">National ArchivesProject BLUE BOOK - Unidentified Flying Objects &#124; National Archives...</span></span></span>

For Exeter, the unresolved status resulted from a combination of factors:

* **Strong but limited testimony:** Several witnesses independently reported unusual lights and an object, including two police officers, giving the case greater weight than a single-person sighting. However, there was no physical evidence such as photographs, material samples, or instrument data to confirm the report.<span class="citation-link-wrap"><a class="citation-inline-link" href="https://www.govweird.com/topics/ufo/project-blue-book/exeter-nh-september-1965" target="_blank" rel="noopener noreferrer nofollow" aria-label="View source: govweird.com">[govweird]</a><span class="citation-popover" role="note"><span class="citation-popover-source">govweird.com</span><span class="citation-popover-title">exeter nh september 1965</span><span class="citation-popover-snippet">Project Blue Book: Exeter, New Hampshire, September 1965 · govweirdSeptember 3, 1965...</span><span class="citation-popover-meta">Published: september 1965</span></span></span>
* **Incomplete conventional explanation:** Military activity provided a possible source of confusion, but the Air Force did not demonstrate that the exercise aircraft matched the reported event closely enough to close the case.<span class="citation-link-wrap"><a class="citation-inline-link" href="https://www.govweird.com/topics/ufo/project-blue-book/exeter-nh-september-1965" target="_blank" rel="noopener noreferrer nofollow" aria-label="View source: govweird.com">[govweird]</a><span class="citation-popover" role="note"><span class="citation-popover-source">govweird.com</span><span class="citation-popover-title">exeter nh september 1965</span><span class="citation-popover-snippet">Project Blue Book: Exeter, New Hampshire, September 1965 · govweirdSeptember 3, 1965...</span><span class="citation-popover-meta">Published: september 1965</span></span></span>
* **Limits of eyewitness evidence:** Even reliable observers can struggle to judge distance, size, speed, and shape during a brief night-time observation. This meant that testimony could establish that something unusual was seen, but not necessarily identify what it was.<span class="citation-link-wrap"><a class="citation-inline-link" href="https://www.nicap.org/reports/650903exeter_hynek.htm" target="_blank" rel="noopener noreferrer nofollow" aria-label="View source: nicap.org">[NICAP]</a><span class="citation-popover" role="note"><span class="citation-popover-source">nicap.org</span><span class="citation-popover-snippet">exeter2...</span></span></span>

The Exeter case therefore occupies an important middle ground in Project Blue Book history. It was not classified as evidence of extraterrestrial technology, but neither was it reduced to a confirmed aircraft, planet, or atmospheric event. Its importance lies in showing how an official investigation handled a case where credible reports existed but the available evidence was insufficient for a final identification.<span class="citation-link-wrap"><a class="citation-inline-link" href="https://www.govweird.com/topics/ufo/project-blue-book/exeter-nh-september-1965" target="_blank" rel="noopener noreferrer nofollow" aria-label="View source: govweird.com">[govweird]</a><span class="citation-popover" role="note"><span class="citation-popover-source">govweird.com</span><span class="citation-popover-title">exeter nh september 1965</span><span class="citation-popover-snippet">Project Blue Book: Exeter, New Hampshire, September 1965 · govweirdSeptember 3, 1965...</span><span class="citation-popover-meta">Published: september 1965</span></span></span>

## The meaning of an unidentified classification

The word “unidentified” has often been misunderstood in discussions of Project Blue Book. Within the Air Force system, it was an administrative category indicating that investigators had not found a satisfactory explanation. It was not equivalent to “alien”, “advanced technology”, or “proven mystery”.<span class="citation-link-wrap"><a class="citation-inline-link" href="https://www.archives.gov/research/military/air-force/ufos" target="_blank" rel="noopener noreferrer nofollow" aria-label="View source: archives.gov">[National Archives]</a><span class="citation-popover" role="note"><span class="citation-popover-source">archives.gov</span><span class="citation-popover-title">National Archives Project BLUE BOOK</span><span class="citation-popover-snippet">National ArchivesProject BLUE BOOK - Unidentified Flying Objects &#124; National Archives...</span></span></span>

At the same time, an unidentified classification was not meaningless. It marked cases where available information resisted a confident explanation. Exeter remained notable because the investigation involved official records, trained witnesses, and a serious attempt to compare testimony against known aviation activity. The unresolved outcome reflected the limits of the evidence rather than a conclusion in favour of any single interpretation.<span class="citation-link-wrap"><a class="citation-inline-link" href="https://www.govweird.com/topics/ufo/project-blue-book/exeter-nh-september-1965" target="_blank" rel="noopener noreferrer nofollow" aria-label="View source: govweird.com">[govweird]</a><span class="citation-popover" role="note"><span class="citation-popover-source">govweird.com</span><span class="citation-popover-title">exeter nh september 1965</span><span class="citation-popover-snippet">Project Blue Book: Exeter, New Hampshire, September 1965 · govweirdSeptember 3, 1965...</span><span class="citation-popover-meta">Published: september 1965</span></span></span>

The lasting debate over Exeter comes from this unresolved balance: supporters point to the credibility of the witnesses and the failure of the proposed explanations to fully account for the event, while sceptical interpretations emphasise the weaknesses of night-time perception and the possibility of ordinary aircraft-related confusion. Project Blue Book’s final decision preserved that uncertainty rather than resolving it.<span class="citation-link-wrap"><a class="citation-inline-link" href="https://www.govweird.com/topics/ufo/project-blue-book/exeter-nh-september-1965" target="_blank" rel="noopener noreferrer nofollow" aria-label="View source: govweird.com">[govweird]</a><span class="citation-popover" role="note"><span class="citation-popover-source">govweird.com</span><span class="citation-popover-title">exeter nh september 1965</span><span class="citation-popover-snippet">Project Blue Book: Exeter, New Hampshire, September 1965 · govweirdSeptember 3, 1965...</span><span class="citation-popover-meta">Published: september 1965</span></span></span>

    if (!cfg) return '#';
    var template = String(cfg.url_template || 'https://www.ebay.com/sch/i.html?_nkw={query}');
    var url = template.replace('{query}', encodeQuery(query || '')).replace('{query_plain}', String(query || ''));
    var joiner = url.indexOf('?') >= 0 ? '&' : '?';
    var params = [];
    if (cfg.mkrid) params.push('mkrid=' + encodeURIComponent(cfg.mkrid));
    if (cfg.campaign_id) params.push('campid=' + encodeURIComponent(cfg.campaign_id));
    params.push('mkevt=1');
    params.push('mkcid=1');
    params.push('toolid=' + encodeURIComponent(cfg.tool_id || '10001'));
    if (reference) params.push('customid=' + encodeURIComponent(reference).slice(0, 256));
    return url + joiner + params.join('&');
  }
  function domainLabel(marketId) {
    var cfg = markets[marketId] || markets[defaultMarket] || {};
    return cfg.domain_label || 'eBay';
  }
  function flagClass(marketId) {
    return 'fr-ebay-market-flag fr-ebay-market-flag--' + String(marketId || '').toLowerCase().replace(/_/g, '-').replace(/[^a-z0-9-]+/g, '');
  }
  function closeMenu(section) {
    var menu = section.querySelector('[data-ebay-market-menu]');
    var trigger = section.querySelector('[data-ebay-market-trigger]');
    var picker = section.querySelector('.fr-ebay-market-picker');
    if (menu) menu.hidden = true;
    if (trigger) trigger.setAttribute('aria-expanded', 'false');
    if (picker) picker.classList.remove('fr-ebay-market-picker--open');
  }
  function availableMarkets(section) {
    var select = section.querySelector('[data-ebay-market-select]');
    if (select) {
      return Array.prototype.slice.call(select.options)
        .map(function (option) { return option.value; })
        .filter(function (marketId) { return !!markets[marketId]; });
    }
    return Array.prototype.slice.call(section.querySelectorAll('[data-ebay-market-button]'))
      .map(function (button) { return button.getAttribute('data-ebay-market-button'); })
      .filter(function (marketId) { return !!markets[marketId]; });
  }
  function applyMarket(section, marketId, persist) {
    var available = availableMarkets(section);
    if (available.indexOf(marketId)< 0) marketId = available[0] || defaultMarket;
    Array.prototype.slice.call(section.querySelectorAll('[data-ebay-localized-link]')).forEach(function (link) {
      var query = link.getAttribute('data-ebay-query') || '';
      var reference = link.getAttribute('data-ebay-reference') || '';
      link.setAttribute('href', buildUrl(query, reference, marketId));
    });
    var select = section.querySelector('[data-ebay-market-select]');
    if (select && available.indexOf(marketId) >= 0) select.value = marketId;
    var selectedText = marketId;
    if (select && select.selectedIndex >= 0) selectedText = select.options[select.selectedIndex].text;
    Array.prototype.slice.call(section.querySelectorAll('[data-ebay-selected-market-label]')).forEach(function (label) {
      label.textContent = selectedText;
    });
    Array.prototype.slice.call(section.querySelectorAll('[data-ebay-selected-market-flag], [data-ebay-trigger-market-flag]')).forEach(function (flag) {
      flag.className = flagClass(marketId);
    });
    Array.prototype.slice.call(section.querySelectorAll('[data-ebay-trigger-market-label]')).forEach(function (label) {
      label.textContent = selectedText;
    });
    Array.prototype.slice.call(section.querySelectorAll('[data-ebay-domain-label]')).forEach(function (label) {
      label.textContent = domainLabel(marketId);
    });
    Array.prototype.slice.call(section.querySelectorAll('[data-ebay-market-option]')).forEach(function (button) {
      button.setAttribute('aria-selected', button.getAttribute('data-ebay-market-option') === marketId ? 'true' : 'false');
    });
    Array.prototype.slice.call(section.querySelectorAll('[data-ebay-market-button]')).forEach(function (button) {
      var active = button.getAttribute('data-ebay-market-button') === marketId;
      button.setAttribute('aria-pressed', active ? 'true' : 'false');
    });
    section.setAttribute('data-ebay-selected-market', marketId);
    if (persist) {
      try { if (window.localStorage) localStorage.setItem('phoenix-ebay-market', marketId); } catch (err) {}
    }
    closeMenu(section);
  }
  sections.forEach(function (section) {
    if (section.getAttribute('data-ebay-localized-init') === '1') return;
    section.setAttribute('data-ebay-localized-init', '1');
    var available = availableMarkets(section);
    var marketId = defaultMarket;
    if (window.PhoenixAffiliateLocation && window.PhoenixAffiliateLocation.inferMarket) {
      marketId = window.PhoenixAffiliateLocation.inferMarket(available, {
        storageKey: 'phoenix-ebay-market',
        defaultMarket: defaultMarket
      });
    } else if (available.indexOf(defaultMarket)< 0) {
      marketId = available[0] || defaultMarket;
    }
    var select = section.querySelector('[data-ebay-market-select]');
    if (select) {
      select.addEventListener('change', function () {
        applyMarket(section, select.value, true);
      });
    }
    var trigger = section.querySelector('[data-ebay-market-trigger]');
    var menu = section.querySelector('[data-ebay-market-menu]');
    if (trigger && menu) {
      trigger.addEventListener('click', function (event) {
        event.stopPropagation();
        var expanded = trigger.getAttribute('aria-expanded') === 'true';
        menu.hidden = expanded;
        trigger.setAttribute('aria-expanded', expanded ? 'false' : 'true');
        var picker = trigger.closest('.fr-ebay-market-picker');
        if (picker) picker.classList.toggle('fr-ebay-market-picker--open', !expanded);
      });
      Array.prototype.slice.call(menu.querySelectorAll('[data-ebay-market-option]')).forEach(function (button) {
        button.addEventListener('click', function (event) {
          event.stopPropagation();
          applyMarket(section, button.getAttribute('data-ebay-market-option'), true);
        });
      });
      document.addEventListener('click', function () { closeMenu(section); });
    }
    Array.prototype.slice.call(section.querySelectorAll('[data-ebay-market-button]')).forEach(function (button) {
      button.addEventListener('click', function () {
        applyMarket(section, button.getAttribute('data-ebay-market-button'), true);
      });
    });
    applyMarket(section, marketId, false);
  });
})();
</script>
