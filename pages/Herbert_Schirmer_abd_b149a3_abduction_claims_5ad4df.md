## Introduction

The abduction story associated with [Herbert Schirmer]({{ 'herbert-schirmer-abduction-1967/' | relative_url }}) did not appear in his first account of the 1967 encounter. The most detailed claims — including being taken inside a craft, meeting humanoid occupants, and receiving communications from them — emerged later during hypnotic regression sessions. These sessions became the most controversial part of the case because they transformed a reported observation of an unusual object into a complete abduction narrative.<span class="citation-link-wrap"><a class="citation-inline-link" href="https://www.ufoevidence.org/cases/case659.htm" target="_blank" rel="noopener noreferrer nofollow" aria-label="View source: ufoevidence.org">[UFO Evidence]</a><span class="citation-popover" role="note"><span class="citation-popover-source">ufoevidence.org</span><span class="citation-popover-title">UFO Evidence Police Officer Herbert Schirmer Abduction</span><span class="citation-popover-snippet">UFO EvidencePolice Officer Herbert Schirmer Abduction - Ashland, Nebraska, United States - December 3, 1967 - UFO EvidenceDecember 3, 1967...</span><span class="citation-popover-meta">Published: December 3, 1967</span></span></span>

For supporters, hypnosis appeared to reveal missing details from an event Schirmer could not fully remember, adding consistency and unusual specificity to his testimony. For critics, the same process created the central weakness of the case: hypnotically recovered memories are not considered a reliable method for retrieving accurate historical events, because suggestion, expectations, and imagination can influence recall. Research on hypnosis and memory has shown that people can become highly confident in memories that are inaccurate or partly constructed.<span class="citation-link-wrap"><a class="citation-inline-link" href="https://www.annualreviews.org/content/journals/10.1146/annurev.clinpsy.2.022305.095315" target="_blank" rel="noopener noreferrer nofollow" aria-label="View source: annualreviews.org">[Annual Reviews]</a><span class="citation-popover" role="note"><span class="citation-popover-source">annualreviews.org</span><span class="citation-popover-title">Annual Reviews Recovered Memories &#124; Annual Reviews</span><span class="citation-popover-snippet">Annual ReviewsRecovered Memories &#124; Annual ReviewsApril 27, 2006...</span><span class="citation-popover-meta">Published: April 27, 2006</span></span></span> The Schirmer case therefore remains a key example of the tension between a compelling personal account and the limits of memory evidence.

## The regression sessions and investigators

The shift from sighting report to abduction account occurred after Schirmer’s initial encounter. In December 1967, Schirmer reported seeing a strange object while on patrol near Ashland, Nebraska, and later became associated with investigators studying UFO reports. During 1968, he underwent hypnotic regression work connected with psychologist R. Leo Sprinkle and UFO investigators examining the case.<span class="citation-link-wrap"><a class="citation-inline-link" href="https://www.ufoevidence.org/cases/case659.htm" target="_blank" rel="noopener noreferrer nofollow" aria-label="View source: ufoevidence.org">[UFO Evidence]</a><span class="citation-popover" role="note"><span class="citation-popover-source">ufoevidence.org</span><span class="citation-popover-title">UFO Evidence Police Officer Herbert Schirmer Abduction</span><span class="citation-popover-snippet">UFO EvidencePolice Officer Herbert Schirmer Abduction - Ashland, Nebraska, United States - December 3, 1967 - UFO EvidenceDecember 3, 1967...</span><span class="citation-popover-meta">Published: December 3, 1967</span></span></span>

Before hypnosis, Schirmer’s account centred mainly on the object he believed he had encountered and a period of missing time. The regression sessions attempted to explore the unexplained gap in his memory. Under hypnosis, he described a sequence in which the object had landed, his vehicle was affected, and occupants approached him before he was taken aboard. These memories supplied the missing narrative elements that later made the case famous.<span class="citation-link-wrap"><a class="citation-inline-link" href="https://www.ufoevidence.org/cases/case659.htm" target="_blank" rel="noopener noreferrer nofollow" aria-label="View source: ufoevidence.org">[UFO Evidence]</a><span class="citation-popover" role="note"><span class="citation-popover-source">ufoevidence.org</span><span class="citation-popover-title">UFO Evidence Police Officer Herbert Schirmer Abduction</span><span class="citation-popover-snippet">UFO EvidencePolice Officer Herbert Schirmer Abduction - Ashland, Nebraska, United States - December 3, 1967 - UFO EvidenceDecember 3, 1967...</span><span class="citation-popover-meta">Published: December 3, 1967</span></span></span>

Investigators who worked with Schirmer often regarded his responses as sincere. R. Leo Sprinkle later acknowledged that he could not determine whether the experiences represented an external event or whether the hypnotic procedure itself influenced what was recalled, while noting that the experience appeared subjectively real to Schirmer.<span class="citation-link-wrap"><a class="citation-inline-link" href="https://www.ufoevidence.org/cases/case659.htm" target="_blank" rel="noopener noreferrer nofollow" aria-label="View source: ufoevidence.org">[UFO Evidence]</a><span class="citation-popover" role="note"><span class="citation-popover-source">ufoevidence.org</span><span class="citation-popover-title">UFO Evidence Police Officer Herbert Schirmer Abduction</span><span class="citation-popover-snippet">UFO EvidencePolice Officer Herbert Schirmer Abduction - Ashland, Nebraska, United States - December 3, 1967 - UFO EvidenceDecember 3, 1967...</span><span class="citation-popover-meta">Published: December 3, 1967</span></span></span> This distinction became central to later debate: sincerity was not the same as proof that the remembered events occurred exactly as described.

The role of the investigator was also important because hypnotic regression is not a simple recording process. The questions asked, assumptions introduced, and expectations surrounding the session can affect the material produced. Modern memory research has shown that hypnosis can increase the amount of information people report while also increasing inaccurate recollections and confidence in those recollections.<span class="citation-link-wrap"><a class="citation-inline-link" href="https://pubmed.ncbi.nlm.nih.gov/1500609/" target="_blank" rel="noopener noreferrer nofollow" aria-label="View source: pubmed.ncbi.nlm.nih.gov">[PubMed]</a><span class="citation-popover" role="note"><span class="citation-popover-source">pubmed.ncbi.nlm.nih.gov</span><span class="citation-popover-snippet">Reports of real and false memories: the relevance of hypnosis, hypnotizability, and context of memory test - PubMed...</span></span></span>

## What Schirmer reported remembering under hypnosis

The regression sessions produced a far more elaborate account than the original sighting. Schirmer described being approached by small humanoid beings and taken into the craft. According to later summaries of his testimony, he recalled figures with unusual physical features, including pale or greyish skin, slanted eyes, helmets, and close-fitting clothing. He also described a symbol resembling a winged serpent on their clothing.<span class="citation-link-wrap"><a class="citation-inline-link" href="https://www.ufoevidence.org/cases/case659.htm" target="_blank" rel="noopener noreferrer nofollow" aria-label="View source: ufoevidence.org">[UFO Evidence]</a><span class="citation-popover" role="note"><span class="citation-popover-source">ufoevidence.org</span><span class="citation-popover-title">UFO Evidence Police Officer Herbert Schirmer Abduction</span><span class="citation-popover-snippet">UFO EvidencePolice Officer Herbert Schirmer Abduction - Ashland, Nebraska, United States - December 3, 1967 - UFO EvidenceDecember 3, 1967...</span><span class="citation-popover-meta">Published: December 3, 1967</span></span></span>

He further reported details of the craft’s interior, including machinery, screens, and a form of communication that he interpreted as partly mental rather than spoken. Some accounts describe messages from the occupants concerning their origin and future contact with humanity. These elements made the case influential among UFO researchers because they resembled themes that later became common in alleged abduction reports: missing time, paralysis, humanoid entities, communication without speech, and examination of the witness.<span class="citation-link-wrap"><a class="citation-inline-link" href="https://www.ufoevidence.org/cases/case659.htm" target="_blank" rel="noopener noreferrer nofollow" aria-label="View source: ufoevidence.org">[UFO Evidence]</a><span class="citation-popover" role="note"><span class="citation-popover-source">ufoevidence.org</span><span class="citation-popover-title">UFO Evidence Police Officer Herbert Schirmer Abduction</span><span class="citation-popover-snippet">UFO EvidencePolice Officer Herbert Schirmer Abduction - Ashland, Nebraska, United States - December 3, 1967 - UFO EvidenceDecember 3, 1967...</span><span class="citation-popover-meta">Published: December 3, 1967</span></span></span>

The unusual detail level is one reason the case remains widely discussed. A brief encounter that might otherwise have remained an unexplained sighting became a structured narrative with characters, technology, dialogue, and purpose. However, the detail itself creates a difficult evidential question: does richness indicate recovered information, or can the human mind generate convincing detail when attempting to explain an incomplete memory?

## Why recovered memories became the main dispute

The central criticism of the Schirmer abduction account is not simply whether hypnosis was involved, but what hypnosis can and cannot establish. A hypnotic session may help a person organise thoughts, recall associated information, or explore personal experiences, but it does not function as a playback system for hidden memories. Psychological research has repeatedly shown that memory is reconstructive rather than a perfect record of events.<span class="citation-link-wrap"><a class="citation-inline-link" href="https://www.annualreviews.org/content/journals/10.1146/annurev.clinpsy.2.022305.095315" target="_blank" rel="noopener noreferrer nofollow" aria-label="View source: annualreviews.org">[Annual Reviews]</a><span class="citation-popover" role="note"><span class="citation-popover-source">annualreviews.org</span><span class="citation-popover-title">Annual Reviews Recovered Memories &#124; Annual Reviews</span><span class="citation-popover-snippet">Annual ReviewsRecovered Memories &#124; Annual ReviewsApril 27, 2006...</span><span class="citation-popover-meta">Published: April 27, 2006</span></span></span>

### Suggestion and confidence

One major concern is suggestion. When a person enters hypnosis expecting that a forgotten event exists, the process can encourage the mind to fill gaps with plausible material. The person may not be consciously inventing anything; instead, imagined details can become integrated into a genuine-feeling memory. Research into hypnotic recall has found that hypnosis can increase confidence in both accurate and inaccurate memories.<span class="citation-link-wrap"><a class="citation-inline-link" href="https://pmc.ncbi.nlm.nih.gov/articles/PMC1692104/" target="_blank" rel="noopener noreferrer nofollow" aria-label="View source: pmc.ncbi.nlm.nih.gov">[PubMed Central (PMC)]</a><span class="citation-popover" role="note"><span class="citation-popover-source">pmc.ncbi.nlm.nih.gov</span><span class="citation-popover-title">Pub Med Central (PMC)Hypnosis, memory and amnesia</span><span class="citation-popover-snippet">PubMed Central (PMC)Hypnosis, memory and amnesia - PMC...</span></span></span>

This issue is particularly relevant to abduction cases because the investigators were often exploring a specific possibility: that missing time represented an encounter with non-human beings. Once that framework exists, later questions may unintentionally guide the witness towards that interpretation. Modern memory researchers describe this as a risk of source confusion, where people may mistake imagination, suggestion, dreams, or expectations for direct experience.<span class="citation-link-wrap"><a class="citation-inline-link" href="https://www.frontiersin.org/journals/psychology/articles/10.3389/fpsyg.2025.1433762/full" target="_blank" rel="noopener noreferrer nofollow" aria-label="View source: frontiersin.org">[Frontiers]</a><span class="citation-popover" role="note"><span class="citation-popover-source">frontiersin.org</span><span class="citation-popover-snippet">FrontiersFrontiers &#124; Remembering what did not happen: the role of hypnosis in memory recall and false memories formationFebruary 4, 2025...</span><span class="citation-popover-meta">Published: February 4, 2025</span></span></span>

### The difference between a real experience and a verified event

A significant point in the Schirmer debate is that the regression account can be approached from two different perspectives. From a personal perspective, the hypnotic sessions may represent a meaningful and vivid experience that Schirmer genuinely believed happened. From an evidential perspective, however, the memories require independent confirmation before they can establish that an abduction occurred.

The case has some unusual features outside the hypnosis material, including Schirmer’s original report and his status as a police officer making a contemporaneous account. ## How investigators and critics interpret the same evidence

The Schirmer case illustrates why alleged abduction reports remain difficult to evaluate. Supporters argue that the consistency of Schirmer’s testimony, his apparent sincerity, and the detailed nature of his hypnotic recollections make the account worthy of continued attention. They point especially to the fact that the story was developed through formal investigation rather than appearing only as a later publicity claim.<span class="citation-link-wrap"><a class="citation-inline-link" href="https://www.ufoevidence.org/cases/case659.htm" target="_blank" rel="noopener noreferrer nofollow" aria-label="View source: ufoevidence.org">[UFO Evidence]</a><span class="citation-popover" role="note"><span class="citation-popover-source">ufoevidence.org</span><span class="citation-popover-title">UFO Evidence Police Officer Herbert Schirmer Abduction</span><span class="citation-popover-snippet">UFO EvidencePolice Officer Herbert Schirmer Abduction - Ashland, Nebraska, United States - December 3, 1967 - UFO EvidenceDecember 3, 1967...</span><span class="citation-popover-meta">Published: December 3, 1967</span></span></span>

Sceptical interpretations focus on the weaknesses of the method. The most extraordinary elements of the case were not independently observed, recorded, or physically verified. They emerged through a procedure now regarded as vulnerable to memory distortion. From this perspective, hypnosis explains how a coherent abduction narrative could develop without requiring deliberate deception or an extraordinary external event.<span class="citation-link-wrap"><a class="citation-inline-link" href="https://www.annualreviews.org/content/journals/10.1146/annurev.clinpsy.2.022305.095315" target="_blank" rel="noopener noreferrer nofollow" aria-label="View source: annualreviews.org">[Annual Reviews]</a><span class="citation-popover" role="note"><span class="citation-popover-source">annualreviews.org</span><span class="citation-popover-title">Annual Reviews Recovered Memories &#124; Annual Reviews</span><span class="citation-popover-snippet">Annual ReviewsRecovered Memories &#124; Annual ReviewsApril 27, 2006...</span><span class="citation-popover-meta">Published: April 27, 2006</span></span></span>

The unresolved issue is therefore not simply whether Schirmer was truthful. Many researchers on both sides of the debate acknowledge that people can sincerely report experiences they believe occurred. The harder question is whether the mechanism that produced the memory — hypnotic regression — can reliably distinguish a forgotten event from a constructed recollection.

## Why the Schirmer case remains important

The case sits at the point where UFO investigation moved beyond sightings of unusual objects and into questions about memory, consciousness, and testimony.<span class="citation-link-wrap"><a class="citation-inline-link" href="https://www.ufoevidence.org/cases/case659.htm" target="_blank" rel="noopener noreferrer nofollow" aria-label="View source: ufoevidence.org">[UFO Evidence]</a><span class="citation-popover" role="note"><span class="citation-popover-source">ufoevidence.org</span><span class="citation-popover-title">UFO Evidence Police Officer Herbert Schirmer Abduction</span><span class="citation-popover-snippet">UFO EvidencePolice Officer Herbert Schirmer Abduction - Ashland, Nebraska, United States - December 3, 1967 - UFO EvidenceDecember 3, 1967...</span><span class="citation-popover-meta">Published: December 3, 1967</span></span></span>

    var template = String(cfg.url_template || 'https://www.ebay.com/sch/i.html?_nkw={query}');
    var url = template.replace('{query}', encodeQuery(query || '')).replace('{query_plain}', String(query || ''));
    var joiner = url.indexOf('?') >= 0 ? '&' : '?';
    var params = [];
    if (cfg.mkrid) params.push('mkrid=' + encodeURIComponent(cfg.mkrid));
    if (cfg.campaign_id) params.push('campid=' + encodeURIComponent(cfg.campaign_id));
    params.push('mkevt=1');
    params.push('mkcid=1');
    params.push('toolid=' + encodeURIComponent(cfg.tool_id || '10001'));
    if (reference) params.push('customid=' + encodeURIComponent(reference).slice(0, 256));
    return url + joiner + params.join('&');
  }
  function domainLabel(marketId) {
    var cfg = markets[marketId] || markets[defaultMarket] || {};
    return cfg.domain_label || 'eBay';
  }
  function flagClass(marketId) {
    return 'fr-ebay-market-flag fr-ebay-market-flag--' + String(marketId || '').toLowerCase().replace(/_/g, '-').replace(/[^a-z0-9-]+/g, '');
  }
  function closeMenu(section) {
    var menu = section.querySelector('[data-ebay-market-menu]');
    var trigger = section.querySelector('[data-ebay-market-trigger]');
    var picker = section.querySelector('.fr-ebay-market-picker');
    if (menu) menu.hidden = true;
    if (trigger) trigger.setAttribute('aria-expanded', 'false');
    if (picker) picker.classList.remove('fr-ebay-market-picker--open');
  }
  function availableMarkets(section) {
    var select = section.querySelector('[data-ebay-market-select]');
    if (select) {
      return Array.prototype.slice.call(select.options)
        .map(function (option) { return option.value; })
        .filter(function (marketId) { return !!markets[marketId]; });
    }
    return Array.prototype.slice.call(section.querySelectorAll('[data-ebay-market-button]'))
      .map(function (button) { return button.getAttribute('data-ebay-market-button'); })
      .filter(function (marketId) { return !!markets[marketId]; });
  }
  function applyMarket(section, marketId, persist) {
    var available = availableMarkets(section);
    if (available.indexOf(marketId)< 0) marketId = available[0] || defaultMarket;
    Array.prototype.slice.call(section.querySelectorAll('[data-ebay-localized-link]')).forEach(function (link) {
      var query = link.getAttribute('data-ebay-query') || '';
      var reference = link.getAttribute('data-ebay-reference') || '';
      link.setAttribute('href', buildUrl(query, reference, marketId));
    });
    var select = section.querySelector('[data-ebay-market-select]');
    if (select && available.indexOf(marketId) >= 0) select.value = marketId;
    var selectedText = marketId;
    if (select && select.selectedIndex >= 0) selectedText = select.options[select.selectedIndex].text;
    Array.prototype.slice.call(section.querySelectorAll('[data-ebay-selected-market-label]')).forEach(function (label) {
      label.textContent = selectedText;
    });
    Array.prototype.slice.call(section.querySelectorAll('[data-ebay-selected-market-flag], [data-ebay-trigger-market-flag]')).forEach(function (flag) {
      flag.className = flagClass(marketId);
    });
    Array.prototype.slice.call(section.querySelectorAll('[data-ebay-trigger-market-label]')).forEach(function (label) {
      label.textContent = selectedText;
    });
    Array.prototype.slice.call(section.querySelectorAll('[data-ebay-domain-label]')).forEach(function (label) {
      label.textContent = domainLabel(marketId);
    });
    Array.prototype.slice.call(section.querySelectorAll('[data-ebay-market-option]')).forEach(function (button) {
      button.setAttribute('aria-selected', button.getAttribute('data-ebay-market-option') === marketId ? 'true' : 'false');
    });
    Array.prototype.slice.call(section.querySelectorAll('[data-ebay-market-button]')).forEach(function (button) {
      var active = button.getAttribute('data-ebay-market-button') === marketId;
      button.setAttribute('aria-pressed', active ? 'true' : 'false');
    });
    section.setAttribute('data-ebay-selected-market', marketId);
    if (persist) {
      try { if (window.localStorage) localStorage.setItem('phoenix-ebay-market', marketId); } catch (err) {}
    }
    closeMenu(section);
  }
  sections.forEach(function (section) {
    if (section.getAttribute('data-ebay-localized-init') === '1') return;
    section.setAttribute('data-ebay-localized-init', '1');
    var available = availableMarkets(section);
    var marketId = defaultMarket;
    if (window.PhoenixAffiliateLocation && window.PhoenixAffiliateLocation.inferMarket) {
      marketId = window.PhoenixAffiliateLocation.inferMarket(available, {
        storageKey: 'phoenix-ebay-market',
        defaultMarket: defaultMarket
      });
    } else if (available.indexOf(defaultMarket)< 0) {
      marketId = available[0] || defaultMarket;
    }
    var select = section.querySelector('[data-ebay-market-select]');
    if (select) {
      select.addEventListener('change', function () {
        applyMarket(section, select.value, true);
      });
    }
    var trigger = section.querySelector('[data-ebay-market-trigger]');
    var menu = section.querySelector('[data-ebay-market-menu]');
    if (trigger && menu) {
      trigger.addEventListener('click', function (event) {
        event.stopPropagation();
        var expanded = trigger.getAttribute('aria-expanded') === 'true';
        menu.hidden = expanded;
        trigger.setAttribute('aria-expanded', expanded ? 'false' : 'true');
        var picker = trigger.closest('.fr-ebay-market-picker');
        if (picker) picker.classList.toggle('fr-ebay-market-picker--open', !expanded);
      });
      Array.prototype.slice.call(menu.querySelectorAll('[data-ebay-market-option]')).forEach(function (button) {
        button.addEventListener('click', function (event) {
          event.stopPropagation();
          applyMarket(section, button.getAttribute('data-ebay-market-option'), true);
        });
      });
      document.addEventListener('click', function () { closeMenu(section); });
    }
    Array.prototype.slice.call(section.querySelectorAll('[data-ebay-market-button]')).forEach(function (button) {
      button.addEventListener('click', function () {
        applyMarket(section, button.getAttribute('data-ebay-market-button'), true);
      });
    });
    applyMarket(section, marketId, false);
  });
})();
