## Introduction

The meteor-and-owl explanation is the main sceptical interpretation of the [Flatwoods incident]({{ 'flatwoods-incident-1952/' | relative_url }}) of 1952: a bright object seen crossing the sky was likely a meteor or other ordinary aerial phenomenon, while the famous “Flatwoods Monster” may have been a misidentified barn owl viewed in poor conditions. The explanation does not require a hoax; instead, it argues that a genuine experience of a strange light and frightening encounter was transformed by darkness, expectation, fear, and limited visibility into an extraordinary story. Investigators have generally separated the case into two problems: identifying the object in the sky and explaining the creature-like figure reported on the hillside.<span class="citation-link-wrap"><a class="citation-inline-link" href="https://skepticalinquirer.org/2000/11/the-flatwoods-ufo-monster/" target="_blank" rel="noopener noreferrer nofollow" aria-label="View source: skepticalinquirer.org">[Skeptical Inquirer]</a><span class="citation-popover" role="note"><span class="citation-popover-source">skepticalinquirer.org</span><span class="citation-popover-title">Skeptical Inquirer The Flatwoods UFO Monster &#124; Skeptical Inquirer</span><span class="citation-popover-snippet">Skeptical Inquirer The Flatwoods UFO Monster &#124; Skeptical Inquirer</span></span></span>

The interpretation remains debated because it explains many features of the report but does not remove every uncertainty. The meteor connection has stronger support from contemporary astronomical and military assessments, while the owl proposal is a reconstruction based on matching witness descriptions to animal behaviour and appearance.<span class="citation-link-wrap"><a class="citation-inline-link" href="https://skepticalinquirer.org/2000/11/the-flatwoods-ufo-monster/" target="_blank" rel="noopener noreferrer nofollow" aria-label="View source: skepticalinquirer.org">[Skeptical Inquirer]</a><span class="citation-popover" role="note"><span class="citation-popover-source">skepticalinquirer.org</span><span class="citation-popover-title">Skeptical Inquirer The Flatwoods UFO Monster &#124; Skeptical Inquirer</span><span class="citation-popover-snippet">Skeptical Inquirer The Flatwoods UFO Monster &#124; Skeptical Inquirer</span></span></span>

## The meteor sighting connection

The first part of the sceptical explanation concerns the bright object that [witnesses]({{ 'witnesses-7fc319/' | relative_url }}) reported seeing over Flatwoods on 12 September 1952. According to later investigators, the object was most likely a meteor — specifically a bright fireball — rather than a spacecraft that landed near the town. The U.S. Air Force’s Project Blue Book records classified the Flatwoods report as an astronomical case, and later summaries of the investigation describe the object as consistent with a meteor sighting.<span class="citation-link-wrap"><a class="citation-inline-link" href="https://flatwoodsmonster.com/" target="_blank" rel="noopener noreferrer nofollow" aria-label="View source: flatwoodsmonster.com">[Flatwoods Monster]</a><span class="citation-popover" role="note"><span class="citation-popover-source">flatwoodsmonster.com</span><span class="citation-popover-snippet">Open source on flatwoodsmonster.com.</span></span></span>

This interpretation fits several features of the original report. The witnesses described a brilliant object moving rapidly across the sky before appearing to descend towards the horizon. Bright meteors can create exactly this type of dramatic impression: a sudden streak of light, a glowing trail, and the illusion that an object has fallen nearby. In 1952, amid widespread public interest in “flying saucers”, an unusual meteor could easily be interpreted as a craft in distress or a crash event, particularly when observers were unsure of the object’s distance and trajectory.<span class="citation-link-wrap"><a class="citation-inline-link" href="https://www.history.com/articles/flatwoods-monster-west-virginia" target="_blank" rel="noopener noreferrer nofollow" aria-label="View source: history.com">[HISTORY]</a><span class="citation-popover" role="note"><span class="citation-popover-source">history.com</span><span class="citation-popover-title">flatwoods monster west virginia</span><span class="citation-popover-snippet">In 1952, the Flatwoods Monster Terrified 6 Kids, a Mom, a Dog—and the Nation &#124; HISTORYJuly 20, 2018...</span><span class="citation-popover-meta">Published: July 20, 2018</span></span></span>

Sceptical investigator Joe Nickell argued that the reported object was likely connected to a meteor observed over parts of the eastern United States on the same evening. His reconstruction also suggested that other lights in the area, including aircraft warning beacons, could have contributed to descriptions of a pulsing red glow associated with the later encounter site.<span class="citation-link-wrap"><a class="citation-inline-link" href="https://skepticalinquirer.org/2000/11/the-flatwoods-ufo-monster/" target="_blank" rel="noopener noreferrer nofollow" aria-label="View source: skepticalinquirer.org">[Skeptical Inquirer]</a><span class="citation-popover" role="note"><span class="citation-popover-source">skepticalinquirer.org</span><span class="citation-popover-title">Skeptical Inquirer The Flatwoods UFO Monster &#124; Skeptical Inquirer</span><span class="citation-popover-snippet">Skeptical Inquirer The Flatwoods UFO Monster &#124; Skeptical Inquirer</span></span></span>

The meteor explanation is strongest for the initial sky event, but it does not automatically explain everything reported at the hillside. A falling or passing meteor does not produce a creature-like figure, unusual sounds, or the fear experienced by the search party. For the full sceptical account, the aerial sighting and the “monster” encounter require two linked but separate explanations.

## The barn owl interpretation

The owl explanation focuses on the creature seen by Kathleen May, Eugene Lemon, and the others who approached the hillside after the sky sighting. Skeptical investigators have suggested that a large barn owl, positioned on or near a tree branch, could have created the main visual elements later associated with the Flatwoods Monster.<span class="citation-link-wrap"><a class="citation-inline-link" href="https://www.skeptic.org.uk/2021/04/what-links-the-flatwoods-monster-the-kelly-hopkinsville-alien-encounter-and-mothman/" target="_blank" rel="noopener noreferrer nofollow" aria-label="View source: skeptic.org.uk">[The Skeptic]</a><span class="citation-popover" role="note"><span class="citation-popover-source">skeptic.org.uk</span><span class="citation-popover-snippet">The SkepticWhat links the Flatwoods Monster, the Kelly–Hopkinsville alien encounter, and Mothman? - The SkepticApril 23, 2021...</span><span class="citation-popover-meta">Published: April 23, 2021</span></span></span>

The proposed match is based on several similarities:

* **The glowing face:** Owls have forward-facing eyes that can reflect torchlight, producing a bright or reddish appearance in darkness.
* **The hood-like head:** A barn owl’s pale, heart-shaped facial disc can appear unusual and almost mask-like when seen briefly.
* **The claw-like hands:** What witnesses interpreted as small hands or arms could have been the bird’s talons gripping a branch.
* **The tall body shape:** Foliage, shadows, and the owl’s position above the ground could have created the impression of a much larger upright figure.<span class="citation-link-wrap"><a class="citation-inline-link" href="https://www.skeptic.org.uk/2021/04/what-links-the-flatwoods-monster-the-kelly-hopkinsville-alien-encounter-and-mothman/" target="_blank" rel="noopener noreferrer nofollow" aria-label="View source: skeptic.org.uk">[The Skeptic]</a><span class="citation-popover" role="note"><span class="citation-popover-source">skeptic.org.uk</span><span class="citation-popover-snippet">The SkepticWhat links the Flatwoods Monster, the Kelly–Hopkinsville alien encounter, and Mothman? - The SkepticApril 23, 2021...</span><span class="citation-popover-meta">Published: April 23, 2021</span></span></span>

Nickell’s reconstruction proposed that a barn owl perched several feet above the ground could appear unusually tall when combined with surrounding vegetation. The “green skirt” or lower body described in some accounts was interpreted as foliage rather than part of a creature. The apparent movement of the figure could also have resulted from the owl shifting position or taking flight.<span class="citation-link-wrap"><a class="citation-inline-link" href="https://www.skeptic.org.uk/2021/04/what-links-the-flatwoods-monster-the-kelly-hopkinsville-alien-encounter-and-mothman/" target="_blank" rel="noopener noreferrer nofollow" aria-label="View source: skeptic.org.uk">[The Skeptic]</a><span class="citation-popover" role="note"><span class="citation-popover-source">skeptic.org.uk</span><span class="citation-popover-snippet">The SkepticWhat links the Flatwoods Monster, the Kelly–Hopkinsville alien encounter, and Mothman? - The SkepticApril 23, 2021...</span><span class="citation-popover-meta">Published: April 23, 2021</span></span></span>

The explanation also addresses the reported sound. Witnesses described unusual noises, sometimes compared to hissing or a high-pitched cry. Barn owls are capable of producing harsh screeches and hissing sounds that are very different from the familiar hoot associated with many owl species. In darkness, an unfamiliar animal call can reinforce the impression that something unknown is nearby.<span class="citation-link-wrap"><a class="citation-inline-link" href="https://www.skeptic.org.uk/2021/04/what-links-the-flatwoods-monster-the-kelly-hopkinsville-alien-encounter-and-mothman/" target="_blank" rel="noopener noreferrer nofollow" aria-label="View source: skeptic.org.uk">[The Skeptic]</a><span class="citation-popover" role="note"><span class="citation-popover-source">skeptic.org.uk</span><span class="citation-popover-snippet">The SkepticWhat links the Flatwoods Monster, the Kelly–Hopkinsville alien encounter, and Mothman? - The SkepticApril 23, 2021...</span><span class="citation-popover-meta">Published: April 23, 2021</span></span></span>

A key point in the owl interpretation is that it does not require witnesses to have invented the encounter. They may have genuinely seen something unusual, but their brains interpreted ambiguous visual information through the expectations already created by the reported “crash” and the search for a mysterious object.<span class="citation-link-wrap"><a class="citation-inline-link" href="https://skepticalinquirer.org/2000/11/the-flatwoods-ufo-monster/" target="_blank" rel="noopener noreferrer nofollow" aria-label="View source: skepticalinquirer.org">[Skeptical Inquirer]</a><span class="citation-popover" role="note"><span class="citation-popover-source">skepticalinquirer.org</span><span class="citation-popover-title">Skeptical Inquirer The Flatwoods UFO Monster &#124; Skeptical Inquirer</span><span class="citation-popover-snippet">Skeptical Inquirer The Flatwoods UFO Monster &#124; Skeptical Inquirer</span></span></span>

## Limits of the sceptical explanation

The meteor-and-owl account is influential because it offers ordinary mechanisms for the two most dramatic parts of the Flatwoods story. However, critics argue that it remains a reconstruction rather than a proven identification. No owl was recovered from the scene, and there is no surviving physical evidence that definitively demonstrates what the witnesses saw.<span class="citation-link-wrap"><a class="citation-inline-link" href="https://science.howstuffworks.com/science-vs-myth/strange-creatures/flatwoods-monster.htm" target="_blank" rel="noopener noreferrer nofollow" aria-label="View source: science.howstuffworks.com">[HowStuffWorks Science]</a><span class="citation-popover" role="note"><span class="citation-popover-source">science.howstuffworks.com</span><span class="citation-popover-snippet">Open source on howstuffworks.com.</span></span></span>

One challenge is the scale of the reported figure. Some witnesses described a very large entity, often remembered as around three metres tall, with a distinctive body shape. Supporters of the owl explanation argue that darkness, distance, and fear could greatly distort size perception, while critics question whether an owl could realistically account for every detail in the reports.<span class="citation-link-wrap"><a class="citation-inline-link" href="https://www.history.com/articles/flatwoods-monster-west-virginia" target="_blank" rel="noopener noreferrer nofollow" aria-label="View source: history.com">[HISTORY]</a><span class="citation-popover" role="note"><span class="citation-popover-source">history.com</span><span class="citation-popover-title">flatwoods monster west virginia</span><span class="citation-popover-snippet">In 1952, the Flatwoods Monster Terrified 6 Kids, a Mom, a Dog—and the Nation &#124; HISTORYJuly 20, 2018...</span><span class="citation-popover-meta">Published: July 20, 2018</span></span></span>

Another issue is that eyewitness accounts developed over time. The Flatwoods description became increasingly fixed through newspaper coverage, illustrations, books, and later retellings. This makes it difficult to determine which details came directly from the immediate observation and which were strengthened by later storytelling.<span class="citation-link-wrap"><a class="citation-inline-link" href="https://www.history.com/articles/flatwoods-monster-west-virginia" target="_blank" rel="noopener noreferrer nofollow" aria-label="View source: history.com">[HISTORY]</a><span class="citation-popover" role="note"><span class="citation-popover-source">history.com</span><span class="citation-popover-title">flatwoods monster west virginia</span><span class="citation-popover-snippet">In 1952, the Flatwoods Monster Terrified 6 Kids, a Mom, a Dog—and the Nation &#124; HISTORYJuly 20, 2018...</span><span class="citation-popover-meta">Published: July 20, 2018</span></span></span>

The strongest assessment is therefore not that the meteor-and-owl explanation proves exactly what happened, but that it provides a coherent naturalistic model. The meteor interpretation explains the unusual object in the sky; the owl interpretation explains how a frightened group could perceive an animal as a strange humanoid figure.     Array.prototype.slice.call(section.querySelectorAll('[data-ebay-market-button]')).forEach(function (button) {
      var active = button.getAttribute('data-ebay-market-button') === marketId;
      button.setAttribute('aria-pressed', active ? 'true' : 'false');
    });
    section.setAttribute('data-ebay-selected-market', marketId);
    if (persist) {
      try { if (window.localStorage) localStorage.setItem('phoenix-ebay-market', marketId); } catch (err) {}
    }
    closeMenu(section);
  }
  sections.forEach(function (section) {
    if (section.getAttribute('data-ebay-localized-init') === '1') return;
    section.setAttribute('data-ebay-localized-init', '1');
    var available = availableMarkets(section);
    var marketId = defaultMarket;
    if (window.PhoenixAffiliateLocation && window.PhoenixAffiliateLocation.inferMarket) {
      marketId = window.PhoenixAffiliateLocation.inferMarket(available, {
        storageKey: 'phoenix-ebay-market',
        defaultMarket: defaultMarket
      });
    } else if (available.indexOf(defaultMarket)< 0) {
      marketId = available[0] || defaultMarket;
    }
    var select = section.querySelector('[data-ebay-market-select]');
    if (select) {
      select.addEventListener('change', function () {
        applyMarket(section, select.value, true);
      });
    }
    var trigger = section.querySelector('[data-ebay-market-trigger]');
    var menu = section.querySelector('[data-ebay-market-menu]');
    if (trigger && menu) {
      trigger.addEventListener('click', function (event) {
        event.stopPropagation();
        var expanded = trigger.getAttribute('aria-expanded') === 'true';
        menu.hidden = expanded;
        trigger.setAttribute('aria-expanded', expanded ? 'false' : 'true');
        var picker = trigger.closest('.fr-ebay-market-picker');
        if (picker) picker.classList.toggle('fr-ebay-market-picker--open', !expanded);
      });
      Array.prototype.slice.call(menu.querySelectorAll('[data-ebay-market-option]')).forEach(function (button) {
        button.addEventListener('click', function (event) {
          event.stopPropagation();
          applyMarket(section, button.getAttribute('data-ebay-market-option'), true);
        });
      });
      document.addEventListener('click', function () { closeMenu(section); });
    }
    Array.prototype.slice.call(section.querySelectorAll('[data-ebay-market-button]')).forEach(function (button) {
      button.addEventListener('click', function () {
        applyMarket(section, button.getAttribute('data-ebay-market-button'), true);
      });
    });
    applyMarket(section, marketId, false);
  });
