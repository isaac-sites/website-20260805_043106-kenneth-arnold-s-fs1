## Introduction

The authenticity debate surrounding the [Ummo photographs]({{ 'ummo-photographs-1967/' | relative_url }}) of 1967 centres on a deceptively simple question: did the images record an unknown craft, or did they capture a carefully arranged object made to look like one? The photographs, associated with the San José de [Valderas sighting]({{ 'the-sighting-455611/' | relative_url }}) near Madrid, became some of the most discussed UFO images in Spain because they appeared to provide physical proof for the wider Ummo story. Yet decades of examination have shifted the debate away from whether the images were merely “clear” photographs and towards a more difficult issue: what exactly can photographic evidence prove about the object that created an image?<span class="citation-link-wrap"><a class="citation-inline-link" href="https://commons.wikimedia.org/wiki/File%3ASan_Jos%C3%A9_de_Valderas_5.jpg" target="_blank" rel="noopener noreferrer nofollow" aria-label="View source: commons.wikimedia.org">[Wikimedia Commons]</a><span class="citation-popover" role="note"><span class="citation-popover-source">commons.wikimedia.org</span><span class="citation-popover-title">Commons File:San José de Valderas 5.jpg</span><span class="citation-popover-snippet">Wikimedia CommonsFile:San José de Valderas 5.jpg - Wikimedia CommonsJanuary 17, 2012...</span><span class="citation-popover-meta">Published: January 17, 2012</span></span></span>

The strongest sceptical interpretation is that the photographs were a staged hoax, probably involving a model object, while supporters have argued that some technical examinations failed to demonstrate conventional trickery. The dispute has continued because different investigations reached different conclusions about scratches on the negatives, possible suspension methods, lighting, and the meaning of later statements by individuals connected with the case.<span class="citation-link-wrap"><a class="citation-inline-link" href="https://ufologie.patrickgross.org/ummo/guardiacivil01.htm" target="_blank" rel="noopener noreferrer nofollow" aria-label="View source: ufologie.patrickgross.org">[Ufologie]</a><span class="citation-popover" role="note"><span class="citation-popover-source">ufologie.patrickgross.org</span><span class="citation-popover-snippet">UFOS at close sight: the claim that Guardia Civil authenticated alleged Ummo spaceship pictures...</span></span></span>

## Claims about the images

The central claim made by supporters of the photographs was that they showed a genuine “Ummo spacecraft” photographed over San José de Valderas on 1 June 1967. The images appeared to show a dark, disc-like object against the sky, and their significance was amplified by the fact that the wider Ummo contact narrative had already generated expectations of an appearance connected with the alleged extraterrestrial visitors.<span class="citation-link-wrap"><a class="citation-inline-link" href="https://commons.wikimedia.org/wiki/File%3ASan_Jos%C3%A9_de_Valderas_5.jpg" target="_blank" rel="noopener noreferrer nofollow" aria-label="View source: commons.wikimedia.org">[Wikimedia Commons]</a><span class="citation-popover" role="note"><span class="citation-popover-source">commons.wikimedia.org</span><span class="citation-popover-title">Commons File:San José de Valderas 5.jpg</span><span class="citation-popover-snippet">Wikimedia CommonsFile:San José de Valderas 5.jpg - Wikimedia CommonsJanuary 17, 2012...</span><span class="citation-popover-meta">Published: January 17, 2012</span></span></span>

Supporters of authenticity focused heavily on the existence of original photographic material rather than only published reproductions. The survival of negatives became a major point in the debate because a genuine negative can provide information about exposure, sequence, and possible manipulation. A later examination arranged through Spanish UFO investigator Juan José Benítez involved five negatives attributed to the Valderas photographs and examined whether they showed signs of fraudulent alteration.<span class="citation-link-wrap"><a class="citation-inline-link" href="https://ignaciodarnaude.es/ficha/analisis-tecnico-de-las-fotografias-de-san-jose-de-valderas-1-junio-1967/" target="_blank" rel="noopener noreferrer nofollow" aria-label="View source: ignaciodarnaude.es">[Ignacio Darnaude Rojas-Marcos.]</a><span class="citation-popover" role="note"><span class="citation-popover-source">ignaciodarnaude.es</span><span class="citation-popover-title">analisis tecnico de las fotografias de san jose de valderas 1 junio 1967</span><span class="citation-popover-snippet">Ignacio Darnaude Rojas-Marcos.ANÁLISIS TÉCNICO DE LAS FOTOGRAFÍAS DE SAN JOSÉ DE VALDERAS UMMO (1 JUNIO 1967) - Ignacio Darnaude Rojas-M...</span></span></span>

However, critics argued that proving a negative had not been physically altered was not the same as proving that it showed an extraterrestrial craft. A photograph can be genuine in the narrow sense that a camera recorded an object, while the object itself may still be an ordinary item, a model, or a staged construction. This distinction became one of the most important points in the authenticity debate.<span class="citation-link-wrap"><a class="citation-inline-link" href="https://ufologie.patrickgross.org/ummo/guardiacivil01.htm" target="_blank" rel="noopener noreferrer nofollow" aria-label="View source: ufologie.patrickgross.org">[Ufologie]</a><span class="citation-popover" role="note"><span class="citation-popover-source">ufologie.patrickgross.org</span><span class="citation-popover-snippet">UFOS at close sight: the claim that Guardia Civil authenticated alleged Ummo spaceship pictures...</span></span></span>

## Technical objections and tests

### The model-and-thread explanation

One of the most influential criticisms was that the object could have been a small model suspended in front of the camera. Investigators including Claude Poher of the French space research organisation CNES and researchers associated with Ground Saucer Watch examined the images and argued that features of the photographs were consistent with a constructed object rather than a large airborne craft.<span class="citation-link-wrap"><a class="citation-inline-link" href="https://ignaciodarnaude.es/ficha/analisis-tecnico-de-las-fotografias-de-san-jose-de-valderas-1-junio-1967/" target="_blank" rel="noopener noreferrer nofollow" aria-label="View source: ignaciodarnaude.es">[Ignacio Darnaude Rojas-Marcos.]</a><span class="citation-popover" role="note"><span class="citation-popover-source">ignaciodarnaude.es</span><span class="citation-popover-title">analisis tecnico de las fotografias de san jose de valderas 1 junio 1967</span><span class="citation-popover-snippet">Ignacio Darnaude Rojas-Marcos.ANÁLISIS TÉCNICO DE LAS FOTOGRAFÍAS DE SAN JOSÉ DE VALDERAS UMMO (1 JUNIO 1967) - Ignacio Darnaude Rojas-M...</span></span></span>

The proposed mechanism was relatively simple: a miniature object could be positioned at a suitable distance from the camera, with perspective making it appear much larger and farther away. A fine support line or similar method could potentially disappear from ordinary viewing while leaving clues detectable through detailed analysis. This explanation did not require advanced photographic manipulation; it relied on staging the scene before the photograph was taken.<span class="citation-link-wrap"><a class="citation-inline-link" href="https://www.lira.hu/hu/antikvar/idegennyelv/flying-saucer-review-august-1980-antikvar" target="_blank" rel="noopener noreferrer nofollow" aria-label="View source: lira.hu">[Líra]</a><span class="citation-popover" role="note"><span class="citation-popover-source">lira.hu</span><span class="citation-popover-title">flying saucer review august 1980 antikvar</span><span class="citation-popover-snippet">LíraFlying Saucer Review August 1980 [antikvár]...</span><span class="citation-popover-meta">Published: august 1980</span></span></span>

The thread argument later became controversial. Some earlier analyses identified a feature interpreted as a possible suspension line, while a later Guardia Civil examination argued that this feature was a scratch on the negative rather than a thread. Supporters of the photographs presented this as evidence that earlier debunking methods were flawed. Critics responded that removing one suspected feature did not remove the broader problems involving provenance, witness credibility, and photographic interpretation.<span class="citation-link-wrap"><a class="citation-inline-link" href="https://ufologie.patrickgross.org/ummo/guardiacivil01.htm" target="_blank" rel="noopener noreferrer nofollow" aria-label="View source: ufologie.patrickgross.org">[Ufologie]</a><span class="citation-popover" role="note"><span class="citation-popover-source">ufologie.patrickgross.org</span><span class="citation-popover-snippet">UFOS at close sight: the claim that Guardia Civil authenticated alleged Ummo spaceship pictures...</span></span></span>

### The Guardia Civil examination

A major turning point in the debate was a 1996 examination by the criminalistics laboratory of the Spanish Guardia Civil. The analysis looked at the negatives for signs of manipulation and considered whether the images contained photographs of real objects or intentional constructions.<span class="citation-link-wrap"><a class="citation-inline-link" href="https://ignaciodarnaude.es/ficha/analisis-tecnico-de-las-fotografias-de-san-jose-de-valderas-1-junio-1967/" target="_blank" rel="noopener noreferrer nofollow" aria-label="View source: ignaciodarnaude.es">[Ignacio Darnaude Rojas-Marcos.]</a><span class="citation-popover" role="note"><span class="citation-popover-source">ignaciodarnaude.es</span><span class="citation-popover-title">analisis tecnico de las fotografias de san jose de valderas 1 junio 1967</span><span class="citation-popover-snippet">Ignacio Darnaude Rojas-Marcos.ANÁLISIS TÉCNICO DE LAS FOTOGRAFÍAS DE SAN JOSÉ DE VALDERAS UMMO (1 JUNIO 1967) - Ignacio Darnaude Rojas-M...</span></span></span>

Supporters often cited this examination as a validation of the photographs because it did not identify a simple physical alteration of the negatives and rejected the interpretation of the famous “thread” feature as a suspension wire. However, critics stressed that the report did not establish that the object was an unknown craft. A lack of obvious negative tampering does not distinguish between a genuine aircraft and a carefully photographed model.<span class="citation-link-wrap"><a class="citation-inline-link" href="https://ufologie.patrickgross.org/ummo/guardiacivil01.htm" target="_blank" rel="noopener noreferrer nofollow" aria-label="View source: ufologie.patrickgross.org">[Ufologie]</a><span class="citation-popover" role="note"><span class="citation-popover-source">ufologie.patrickgross.org</span><span class="citation-popover-snippet">UFOS at close sight: the claim that Guardia Civil authenticated alleged Ummo spaceship pictures...</span></span></span>

The same analysis also raised questions about aspects of the images, including unusual lighting characteristics and the possibility that some photographic processes or arrangements could have produced the results. This left room for opposing interpretations: one side saw the report as weakening earlier debunking arguments, while the other saw it as insufficient to overcome the wider evidence against authenticity.<span class="citation-link-wrap"><a class="citation-inline-link" href="https://ufologie.patrickgross.org/ummo/guardiacivil01.htm" target="_blank" rel="noopener noreferrer nofollow" aria-label="View source: ufologie.patrickgross.org">[Ufologie]</a><span class="citation-popover" role="note"><span class="citation-popover-source">ufologie.patrickgross.org</span><span class="citation-popover-snippet">UFOS at close sight: the claim that Guardia Civil authenticated alleged Ummo spaceship pictures...</span></span></span>

## Why photographs can mislead

The Ummo photographs demonstrate a recurring problem in analysing unusual images: the camera records light patterns, not explanations. A photograph may accurately capture something in the environment while still leaving unanswered questions about size, distance, identity, and purpose.

In the Valderas case, several factors complicated interpretation:

* **Scale uncertainty:** Without reliable reference measurements, a small object close to the lens can resemble a large object in the sky.
* **Limited perspective information:** A single viewpoint makes it difficult to determine depth or distance.
* **Missing photographic context:** Questions about the complete film sequence, unused frames, and the circumstances of taking the photographs affected assessments of reliability. Critics highlighted gaps in the available photographic record as a reason for continued suspicion.<span class="citation-link-wrap"><a class="citation-inline-link" href="https://ufologie.patrickgross.org/ummo/guardiacivil01.htm" target="_blank" rel="noopener noreferrer nofollow" aria-label="View source: ufologie.patrickgross.org">[Ufologie]</a><span class="citation-popover" role="note"><span class="citation-popover-source">ufologie.patrickgross.org</span><span class="citation-popover-snippet">UFOS at close sight: the claim that Guardia Civil authenticated alleged Ummo spaceship pictures...</span></span></span>
* **Expectation effects:** Because the images appeared within the already established Ummo narrative, viewers were more likely to interpret an ambiguous object according to an existing story.

These issues matter because the photographs became persuasive not only through their appearance but through the surrounding claims: alleged predictions, witness accounts, and links to the broader Ummo mythology. The image itself could not independently confirm those additional claims.

## The role of José Luis Jordán Peña

The debate became more complicated after José Luis Jordán Peña, a figure closely associated with early Ummo investigations, later claimed involvement in creating the photographs. According to accounts of his statements, he described the photographs as part of an “experiment” or hoax connected with the Ummo phenomenon. Some researchers treated these statements as the decisive explanation; others questioned details of the confession and whether every aspect of the event had been conclusively demonstrated.<span class="citation-link-wrap"><a class="citation-inline-link" href="https://www.todocoleccion.net/colecciona-recuerdos/colecciones-unicas/ummo-caso-coleccion" target="_blank" rel="noopener noreferrer nofollow" aria-label="View source: todocoleccion.net">[Todocoleccion]</a><span class="citation-popover" role="note"><span class="citation-popover-source">todocoleccion.net</span><span class="citation-popover-title">UMMO caso de colección &#124; Blog Colecciona Recuerdos</span><span class="citation-popover-snippet">UMMO caso de colección &#124; Blog Colecciona RecuerdosAugust 1, 2018...</span><span class="citation-popover-meta">Published: August 1, 2018</span></span></span>

The importance of Peña’s statements lies less in proving every technical detail of the photographs and more in how they affected the evidential balance. Before the claims, investigators had to choose between competing interpretations of the images. Afterward, the existence of a claimed human source for the construction of the event provided a plausible non-extraterrestrial explanation that matched many earlier objections.<span class="citation-link-wrap"><a class="citation-inline-link" href="https://factorelblog.com/2022/10/28/ummo-el-dia-que-jordan-pena-mostro-sus-cartas-y-nadie-pesco-el-guino/" target="_blank" rel="noopener noreferrer nofollow" aria-label="View source: factorelblog.com">[factorelblog.com]</a><span class="citation-popover" role="note"><span class="citation-popover-source">factorelblog.com</span><span class="citation-popover-title">Ummo: el día que Jordán Peña “mostró sus cartas” y nadie pescó el guiño</span><span class="citation-popover-snippet">Factor el Blog &#124; El Blog de Alejandro Agostinelli...</span></span></span>

## Real craft or clever photograph hoax?

The continuing controversy is not mainly about whether the photographs physically exist. The negatives and prints are part of the historical record. The disagreement concerns what those materials demonstrate.

The case for an unknown craft rests mainly on the argument that some technical objections have not produced a complete explanation of every photographic detail. The case for a hoax rests on a broader combination of factors: suspicious provenance, disputed witness accounts, technical interpretations consistent with a model, and later claims of responsibility.<span class="citation-link-wrap"><a class="citation-inline-link" href="https://ufologie.patrickgross.org/ummo/guardiacivil01.htm" target="_blank" rel="noopener noreferrer nofollow" aria-label="View source: ufologie.patrickgross.org">[Ufologie]</a><span class="citation-popover" role="note"><span class="citation-popover-source">ufologie.patrickgross.org</span><span class="citation-popover-snippet">UFOS at close sight: the claim that Guardia Civil authenticated alleged Ummo spaceship pictures...</span></span></span>

Most historical assessments have therefore treated the Ummo photographs as a probable hoax rather than evidence of an extraterrestrial vehicle. The enduring interest of the case comes from the gap between what a photograph appears to show and what can actually be established from it. The images remain a useful example of how photographic evidence can become convincing through context, expectation, and storytelling as much as through the physical information contained in the image itself.<span class="citation-link-wrap"><a class="citation-inline-link" href="https://ufologie.patrickgross.org/ummo/" target="_blank" rel="noopener noreferrer nofollow" aria-label="View source: ufologie.patrickgross.org">[Ufologie]</a><span class="citation-popover" role="note"><span class="citation-popover-source">ufologie.patrickgross.org</span><span class="citation-popover-snippet">UFOS at close sight: Ummo...</span></span></span>

    if (cfg.campaign_id) params.push('campid=' + encodeURIComponent(cfg.campaign_id));
    params.push('mkevt=1');
    params.push('mkcid=1');
    params.push('toolid=' + encodeURIComponent(cfg.tool_id || '10001'));
    if (reference) params.push('customid=' + encodeURIComponent(reference).slice(0, 256));
    return url + joiner + params.join('&');
  }
  function domainLabel(marketId) {
    var cfg = markets[marketId] || markets[defaultMarket] || {};
    return cfg.domain_label || 'eBay';
  }
  function flagClass(marketId) {
    return 'fr-ebay-market-flag fr-ebay-market-flag--' + String(marketId || '').toLowerCase().replace(/_/g, '-').replace(/[^a-z0-9-]+/g, '');
  }
  function closeMenu(section) {
    var menu = section.querySelector('[data-ebay-market-menu]');
    var trigger = section.querySelector('[data-ebay-market-trigger]');
    var picker = section.querySelector('.fr-ebay-market-picker');
    if (menu) menu.hidden = true;
    if (trigger) trigger.setAttribute('aria-expanded', 'false');
    if (picker) picker.classList.remove('fr-ebay-market-picker--open');
  }
  function availableMarkets(section) {
    var select = section.querySelector('[data-ebay-market-select]');
    if (select) {
      return Array.prototype.slice.call(select.options)
        .map(function (option) { return option.value; })
        .filter(function (marketId) { return !!markets[marketId]; });
    }
    return Array.prototype.slice.call(section.querySelectorAll('[data-ebay-market-button]'))
      .map(function (button) { return button.getAttribute('data-ebay-market-button'); })
      .filter(function (marketId) { return !!markets[marketId]; });
  }
  function applyMarket(section, marketId, persist) {
    var available = availableMarkets(section);
    if (available.indexOf(marketId)< 0) marketId = available[0] || defaultMarket;
    Array.prototype.slice.call(section.querySelectorAll('[data-ebay-localized-link]')).forEach(function (link) {
      var query = link.getAttribute('data-ebay-query') || '';
      var reference = link.getAttribute('data-ebay-reference') || '';
      link.setAttribute('href', buildUrl(query, reference, marketId));
    });
    var select = section.querySelector('[data-ebay-market-select]');
    if (select && available.indexOf(marketId) >= 0) select.value = marketId;
    var selectedText = marketId;
    if (select && select.selectedIndex >= 0) selectedText = select.options[select.selectedIndex].text;
    Array.prototype.slice.call(section.querySelectorAll('[data-ebay-selected-market-label]')).forEach(function (label) {
      label.textContent = selectedText;
    });
    Array.prototype.slice.call(section.querySelectorAll('[data-ebay-selected-market-flag], [data-ebay-trigger-market-flag]')).forEach(function (flag) {
      flag.className = flagClass(marketId);
    });
    Array.prototype.slice.call(section.querySelectorAll('[data-ebay-trigger-market-label]')).forEach(function (label) {
      label.textContent = selectedText;
    });
    Array.prototype.slice.call(section.querySelectorAll('[data-ebay-domain-label]')).forEach(function (label) {
      label.textContent = domainLabel(marketId);
    });
    Array.prototype.slice.call(section.querySelectorAll('[data-ebay-market-option]')).forEach(function (button) {
      button.setAttribute('aria-selected', button.getAttribute('data-ebay-market-option') === marketId ? 'true' : 'false');
    });
    Array.prototype.slice.call(section.querySelectorAll('[data-ebay-market-button]')).forEach(function (button) {
      var active = button.getAttribute('data-ebay-market-button') === marketId;
      button.setAttribute('aria-pressed', active ? 'true' : 'false');
    });
    section.setAttribute('data-ebay-selected-market', marketId);
    if (persist) {
      try { if (window.localStorage) localStorage.setItem('phoenix-ebay-market', marketId); } catch (err) {}
    }
    closeMenu(section);
  }
  sections.forEach(function (section) {
    if (section.getAttribute('data-ebay-localized-init') === '1') return;
    section.setAttribute('data-ebay-localized-init', '1');
    var available = availableMarkets(section);
    var marketId = defaultMarket;
    if (window.PhoenixAffiliateLocation && window.PhoenixAffiliateLocation.inferMarket) {
      marketId = window.PhoenixAffiliateLocation.inferMarket(available, {
        storageKey: 'phoenix-ebay-market',
        defaultMarket: defaultMarket
      });
    } else if (available.indexOf(defaultMarket)< 0) {
      marketId = available[0] || defaultMarket;
    }
    var select = section.querySelector('[data-ebay-market-select]');
    if (select) {
      select.addEventListener('change', function () {
        applyMarket(section, select.value, true);
      });
    }
    var trigger = section.querySelector('[data-ebay-market-trigger]');
    var menu = section.querySelector('[data-ebay-market-menu]');
    if (trigger && menu) {
      trigger.addEventListener('click', function (event) {
        event.stopPropagation();
        var expanded = trigger.getAttribute('aria-expanded') === 'true';
        menu.hidden = expanded;
        trigger.setAttribute('aria-expanded', expanded ? 'false' : 'true');
        var picker = trigger.closest('.fr-ebay-market-picker');
        if (picker) picker.classList.toggle('fr-ebay-market-picker--open', !expanded);
      });
      Array.prototype.slice.call(menu.querySelectorAll('[data-ebay-market-option]')).forEach(function (button) {
        button.addEventListener('click', function (event) {
          event.stopPropagation();
          applyMarket(section, button.getAttribute('data-ebay-market-option'), true);
        });
      });
      document.addEventListener('click', function () { closeMenu(section); });
    }
    Array.prototype.slice.call(section.querySelectorAll('[data-ebay-market-button]')).forEach(function (button) {
      button.addEventListener('click', function () {
        applyMarket(section, button.getAttribute('data-ebay-market-button'), true);
      });
    });
    applyMarket(section, marketId, false);
  });
})();
