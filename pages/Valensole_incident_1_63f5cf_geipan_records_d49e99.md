## Introduction

The French government’s official handling of the [Valensole incident]({{ 'valensole-incident-1965/' | relative_url }}) did not classify the case as a proven extraordinary event; instead, it preserved it as an unresolved report after investigation. Today, the case remains in the archives of GEIPAN (Groupe d’Études et d’Informations sur les Phénomènes Aérospatiaux Non Identifiés), the unidentified aerospace phenomena study group within France’s National Centre for Space Studies (CNES), with a **D classification**. In GEIPAN terminology, this means a phenomenon that was not identified after investigation, not a confirmation of any particular explanation.<span class="citation-link-wrap"><a class="citation-inline-link" href="https://www.cnes-geipan.fr/en/node/46691" target="_blank" rel="noopener noreferrer nofollow" aria-label="View source: cnes-geipan.fr">[Geipan]</a><span class="citation-popover" role="note"><span class="citation-popover-source">cnes-geipan.fr</span><span class="citation-popover-snippet">GeipanVALENSOLE (04) 01.07.1965 &#124; GEIPANJuly 1, 1965...</span><span class="citation-popover-meta">Published: July 1, 1965</span></span></span>

## French investigation and archived documents

The original investigation of the Valensole incident did not begin with GEIPAN because GEIPAN did not yet exist in 1965. The first official response came from the French gendarmerie, which interviewed the witness, inspected the reported landing area and produced written records. Decades later, the case material was incorporated into the documentary archive maintained by GEIPAN, allowing the public to examine the historical record.<span class="citation-link-wrap"><a class="citation-inline-link" href="https://geipan.fr/fr/node/46692" target="_blank" rel="noopener noreferrer nofollow" aria-label="View source: geipan.fr">[Geipan]</a><span class="citation-popover" role="note"><span class="citation-popover-source">geipan.fr</span><span class="citation-popover-snippet">VALENSOLE (04) 01.07.1965 &#124; GEIPAN...</span></span></span>

The archived file contains several important elements:


<div class="content-enhancement content-enhancement--insight-grid" markdown="1">

* The initial witness statement from farmer Maurice Masse, recorded shortly after the reported event.
* A later gendarmerie inspection report documenting measurements and observations at the site.
* Photographic documentation associated with the investigation.
* Additional witness information collected later in 1965.<span class="citation-link-wrap"><a class="citation-inline-link" href="https://geipan.fr/fr/node/46692" target="_blank" rel="noopener noreferrer nofollow" aria-label="View source: geipan.fr">[Geipan]</a><span class="citation-popover" role="note"><span class="citation-popover-source">geipan.fr</span><span class="citation-popover-snippet">VALENSOLE (04) 01.07.1965 &#124; GEIPAN...</span></span></span>

</div>

According to GEIPAN’s case summary, the reported event occurred on 1 July 1965 at around 05:45 in the Alpes-de-Haute-Provence region. The file describes an observation of an unknown object, a claimed close encounter, and reported traces on the ground. The archived description notes that investigators recorded the existence of marks at the location, while also noting that no additional independent witness or surrounding [physical evidence]({{ 'physical-evidence-d499f0/' | relative_url }}) was found.<span class="citation-link-wrap"><a class="citation-inline-link" href="https://www.cnes-geipan.fr/en/node/46691" target="_blank" rel="noopener noreferrer nofollow" aria-label="View source: cnes-geipan.fr">[Geipan]</a><span class="citation-popover" role="note"><span class="citation-popover-source">cnes-geipan.fr</span><span class="citation-popover-snippet">GeipanVALENSOLE (04) 01.07.1965 &#124; GEIPANJuly 1, 1965...</span><span class="citation-popover-meta">Published: July 1, 1965</span></span></span>

This distinction is central to understanding the official record. The gendarmerie investigation documented that a report had been made and that certain features of the scene were examined. It did not establish the nature of the object described by the witness. The archive therefore preserves the investigation history without converting the report into proof of a specific cause.<span class="citation-link-wrap"><a class="citation-inline-link" href="https://geipan.fr/fr/node/46692" target="_blank" rel="noopener noreferrer nofollow" aria-label="View source: geipan.fr">[Geipan]</a><span class="citation-popover" role="note"><span class="citation-popover-source">geipan.fr</span><span class="citation-popover-snippet">VALENSOLE (04) 01.07.1965 &#124; GEIPAN...</span></span></span>

## Why France still lists Valensole unresolved

GEIPAN’s classification system is designed to measure two things: the reliability and quantity of collected information, known as consistency, and the remaining unexplained characteristics after possible explanations have been examined, known as residual strangeness.<span class="citation-link-wrap"><a class="citation-inline-link" href="https://www.geipan.fr/en/node/412" target="_blank" rel="noopener noreferrer nofollow" aria-label="View source: geipan.fr">[Geipan]</a><span class="citation-popover" role="note"><span class="citation-popover-source">geipan.fr</span><span class="citation-popover-title">How does GEIPAN classify observation cases? &#124; GEIPAN</span><span class="citation-popover-snippet">How does GEIPAN classify observation cases? &#124; GEIPAN...</span></span></span>

Under the current classification framework:


<div class="content-enhancement content-enhancement--insight-grid" markdown="1">

* **A** means the phenomenon was identified with certainty.
* **B** means a probable explanation was found.
* **C** means the case cannot be assessed because information is insufficient.
* **D** means the phenomenon remains unidentified after investigation.<span class="citation-link-wrap"><a class="citation-inline-link" href="https://www.geipan.fr/en/node/412" target="_blank" rel="noopener noreferrer nofollow" aria-label="View source: geipan.fr">[Geipan]</a><span class="citation-popover" role="note"><span class="citation-popover-source">geipan.fr</span><span class="citation-popover-title">How does GEIPAN classify observation cases? &#124; GEIPAN</span><span class="citation-popover-snippet">How does GEIPAN classify observation cases? &#124; GEIPAN...</span></span></span>

</div>

Valensole falls into the final category because GEIPAN considers the available information substantial enough to investigate, but insufficient to establish a conventional explanation that fully accounts for the reported event. The classification does not indicate that GEIPAN accepts the witness interpretation; it indicates that the investigation did not resolve the case.<span class="citation-link-wrap"><a class="citation-inline-link" href="https://www.cnes-geipan.fr/en/node/46691" target="_blank" rel="noopener noreferrer nofollow" aria-label="View source: cnes-geipan.fr">[Geipan]</a><span class="citation-popover" role="note"><span class="citation-popover-source">cnes-geipan.fr</span><span class="citation-popover-snippet">GeipanVALENSOLE (04) 01.07.1965 &#124; GEIPANJuly 1, 1965...</span><span class="citation-popover-meta">Published: July 1, 1965</span></span></span>

This is an important point because unidentified cases are sometimes misunderstood. In GEIPAN’s approach, “unidentified” describes the state of the investigation outcome, not the origin of the phenomenon. A D classification does not distinguish between an unknown technology, an unusual natural event, a perception issue, a misinterpretation, or another explanation that cannot currently be demonstrated from the available evidence.<span class="citation-link-wrap"><a class="citation-inline-link" href="https://geipan.fr/en/node/58787" target="_blank" rel="noopener noreferrer nofollow" aria-label="View source: geipan.fr">[Geipan]</a><span class="citation-popover" role="note"><span class="citation-popover-source">geipan.fr</span><span class="citation-popover-title">Classification &#124; GEIPAN</span><span class="citation-popover-snippet">Classification &#124; GEIPAN...</span></span></span>

## Official findings versus unanswered questions

The strength of the Valensole file comes from the unusual combination of elements recorded in the historical documents: a named witness, a close-range account, an official police inquiry and claimed physical traces. These features made it different from many reports that consist only of distant observations or incomplete descriptions.<span class="citation-link-wrap"><a class="citation-inline-link" href="https://geipan.fr/fr/node/46692" target="_blank" rel="noopener noreferrer nofollow" aria-label="View source: geipan.fr">[Geipan]</a><span class="citation-popover" role="note"><span class="citation-popover-source">geipan.fr</span><span class="citation-popover-snippet">VALENSOLE (04) 01.07.1965 &#124; GEIPAN...</span></span></span>

At the same time, the limitations of the evidence explain why the case remains unresolved rather than confirmed. The record lacks several forms of corroboration that would normally strengthen an extraordinary claim:

    return Array.prototype.slice.call(section.querySelectorAll('[data-ebay-market-button]'))
      .map(function (button) { return button.getAttribute('data-ebay-market-button'); })
      .filter(function (marketId) { return !!markets[marketId]; });
  }
  function applyMarket(section, marketId, persist) {
    var available = availableMarkets(section);
    if (available.indexOf(marketId)< 0) marketId = available[0] || defaultMarket;
    Array.prototype.slice.call(section.querySelectorAll('[data-ebay-localized-link]')).forEach(function (link) {
      var query = link.getAttribute('data-ebay-query') || '';
      var reference = link.getAttribute('data-ebay-reference') || '';
      link.setAttribute('href', buildUrl(query, reference, marketId));
    });
    var select = section.querySelector('[data-ebay-market-select]');
    if (select && available.indexOf(marketId) >= 0) select.value = marketId;
    var selectedText = marketId;
    if (select && select.selectedIndex >= 0) selectedText = select.options[select.selectedIndex].text;
    Array.prototype.slice.call(section.querySelectorAll('[data-ebay-selected-market-label]')).forEach(function (label) {
      label.textContent = selectedText;
    });
    Array.prototype.slice.call(section.querySelectorAll('[data-ebay-selected-market-flag], [data-ebay-trigger-market-flag]')).forEach(function (flag) {
      flag.className = flagClass(marketId);
    });
    Array.prototype.slice.call(section.querySelectorAll('[data-ebay-trigger-market-label]')).forEach(function (label) {
      label.textContent = selectedText;
    });
    Array.prototype.slice.call(section.querySelectorAll('[data-ebay-domain-label]')).forEach(function (label) {
      label.textContent = domainLabel(marketId);
    });
    Array.prototype.slice.call(section.querySelectorAll('[data-ebay-market-option]')).forEach(function (button) {
      button.setAttribute('aria-selected', button.getAttribute('data-ebay-market-option') === marketId ? 'true' : 'false');
    });
    Array.prototype.slice.call(section.querySelectorAll('[data-ebay-market-button]')).forEach(function (button) {
      var active = button.getAttribute('data-ebay-market-button') === marketId;
      button.setAttribute('aria-pressed', active ? 'true' : 'false');
    });
    section.setAttribute('data-ebay-selected-market', marketId);
    if (persist) {
      try { if (window.localStorage) localStorage.setItem('phoenix-ebay-market', marketId); } catch (err) {}
    }
    closeMenu(section);
  }
  sections.forEach(function (section) {
    if (section.getAttribute('data-ebay-localized-init') === '1') return;
    section.setAttribute('data-ebay-localized-init', '1');
    var available = availableMarkets(section);
    var marketId = defaultMarket;
    if (window.PhoenixAffiliateLocation && window.PhoenixAffiliateLocation.inferMarket) {
      marketId = window.PhoenixAffiliateLocation.inferMarket(available, {
        storageKey: 'phoenix-ebay-market',
        defaultMarket: defaultMarket
      });
    } else if (available.indexOf(defaultMarket)< 0) {
      marketId = available[0] || defaultMarket;
    }
    var select = section.querySelector('[data-ebay-market-select]');
    if (select) {
      select.addEventListener('change', function () {
        applyMarket(section, select.value, true);
      });
    }
    var trigger = section.querySelector('[data-ebay-market-trigger]');
    var menu = section.querySelector('[data-ebay-market-menu]');
    if (trigger && menu) {
      trigger.addEventListener('click', function (event) {
        event.stopPropagation();
        var expanded = trigger.getAttribute('aria-expanded') === 'true';
        menu.hidden = expanded;
        trigger.setAttribute('aria-expanded', expanded ? 'false' : 'true');
        var picker = trigger.closest('.fr-ebay-market-picker');
        if (picker) picker.classList.toggle('fr-ebay-market-picker--open', !expanded);
      });
      Array.prototype.slice.call(menu.querySelectorAll('[data-ebay-market-option]')).forEach(function (button) {
        button.addEventListener('click', function (event) {
          event.stopPropagation();
          applyMarket(section, button.getAttribute('data-ebay-market-option'), true);
        });
      });
      document.addEventListener('click', function () { closeMenu(section); });
    }
    Array.prototype.slice.call(section.querySelectorAll('[data-ebay-market-button]')).forEach(function (button) {
      button.addEventListener('click', function () {
        applyMarket(section, button.getAttribute('data-ebay-market-button'), true);
      });
    });
    applyMarket(section, marketId, false);
  });
})();
